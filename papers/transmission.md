# 传播

这里的传播是文化传递和网络扩散，不是通信工程。文化传递里，复制、选择、吸引是三种不同的机制。网络扩散是另一套数学。已经接到代码里的公式仍以 `doc/v8.3/memetics_library/` 为准。

## 别人怎么看模因

Olivier Morin。Reasons to be fussy about cultural evolution。Biology and Philosophy 31:447–458，2016。

全文：<https://pmc.ncbi.nlm.nih.gov/articles/PMC4944120/>
DOI：<https://doi.org/10.1007/s10539-016-9516-4>

Morin 回应 Buskell，以及 Acerbi 和 Mesoudi。吸引论和 Boyd、Richerson 一系的文化进化有重叠，分歧在于：稳定是否必须靠高保真模仿和选择。吸引论把明示交流、论证和选择性信任放在模仿前面，并且不把群体选择当成默认解释。

Andrew Buskell。What are cultural attractors? DOI：<https://doi.org/10.1007/s10539-017-9570-6>

本次读到的是出版页上的定义，不是单独下载的 PDF。吸引子不是一件存在脑子里或图里的东西。它是一个理论设定：有些观念变体比别的变体更可能成为转换的结果。转换在种群里是系统的，于是变体的分布会变。句子被记住、语法成形、超自然信念变常见，用的都是这个说明，而不是“有一个模因被原样拷贝”。

Thom Scott-Phillips，Stefaan Blancke，Christophe Heintz。Four misunderstandings about cultural attraction。Evolutionary Anthropology，2018。

摘要页：<https://doi.org/10.1002/evan.21716>

本次打开的是摘要。吸引论是对文化现象做因果说明的研究纲领，也是一种进化说明：文化是一群不同类型的项目，类型的频率随时间变化。它和“文化进化就是复制加选择”不是同一个纲领。

Alberto Acerbi，Mathieu Charbonneau，Helena Miton，Thom Scott-Phillips。Culture without copying or selection。Evolutionary Human Sciences，2021。

出版页：<https://doi.org/10.1017/ehs.2021.47>

种群层面的稳定可以只来自收敛式转换：后一件东西系统地偏向某个形状，不必是前一件的高保真拷贝，也不必有选择。高保真复制如果没有选择，长期会漂。收敛式转换和选择式复制都能让种群看起来稳定，但人口统计上的签名不同。代码在 <https://osf.io/yncws/>。

这和 2026-10-24 的测量是同一类现象。两份草稿对任务原文的平均保真度 0.046，彼此 0.105，偏差为正，复制计数是 0。方向上的靠近不是复制。

## 时间签名没有接上我们的保真度

Acerbi 等把“输入到输出的距离”分成两种：复制时距离一直很低；收敛式转换时距离先高后低。2026-10-24 在跑合成过程之前，把判定写成：逐步保真度至少 6 步，前半段和后半段都 ≥ 0.75 叫复制；前半段 ≤ 0.55 且后半段至少高出 0.25 叫收敛；其余叫未定。手写的六个数能分开这三档。

然后用两个已知过程各走 12 步，每步改写剩余差距的一半，或者每步只改一个词。两种距离分开记：位置对齐的一致比例，以及现有的最长连续词段保真度。

对齐距离把“每步改一个词”判成复制（前后半段都是 0.917）。同一条轨迹的连续词段保真度是 0.708，判成未定。往吸引子走的那条，两种距离的前半段都已经到了 0.78 和 0.83，后半段是 1，于是都被判成复制。过程在前半段里就已经靠近终点，半段平均看不出“先远后近”。

所以这条签名不能换成 `judgeCopy`，也不能拿去给真实草稿贴收敛或复制的标签。阈值保持当初写下的数，不按结果改。

## 种群标签和谱系分开

Claidière、Scott-Phillips、Sperber 2014 把复制写成吸引里保住指定父本的特例。Scott-Phillips、Blancke、Heintz 2018 的摘要把吸引论说成一种进化说明，不把吸引当成可以替换选择的另一件东西。选择仍走 Price 那一笔，不从一次种群快照里读出。

2026-10-24 在跑探针之前写下的标签是：至少一份子本复制了父本，而且子本彼此不比父本更近，叫 replication；没有子本复制父本，但子本之间有复制且偏差为正，叫 attraction；其余叫 undetermined。一次 replication 不因此成为模因。模因仍要繁殖力至少 2、寿命至少 2。

探针覆盖六种种群和一条谱系，七项都按事先写下的标签通过。两份逐字拷贝：父本保真度 1，偏差 0，`parentCopies` 2，标签 replication。两份相同的倒序句：父本保真度 0.25，偏差 0.75，`parentCopies` 0，`peerCopies` 2，标签 attraction。原句谱系不被收录，倒序句被两个不同载体复制之后才收录。一份拷贝加一份无关文本：偏差 -0.5，`parentCopies` 1，标签 replication。单独一份拷贝也是 replication，繁殖力为 1，不收录。两份互不相关的文本是 undetermined。一份完整拷贝混在四份彼此相同、又不复制父本的文本里：父本保真度 0.2，内部保真度 0.6，偏差 0.4，`parentCopies` 1，`peerCopies` 12，标签 undetermined。阈值没有按结果改。`relatePopulation` 把这个标签写进 `mechanism`。审议日志和 `replica_trace` 的一拍记录带上同一个字段。审议日志同时写 `force=unidentified`。一次快照没有频率序列，不能指出是哪一种力。

## 同一步可以配成两种力

Boyd、Richerson 1985 的频率更新，按 Denton、Ram、Liberman、Feldman，PNAS 2020 的公式 (1) 书写。`p` 是变体 A 的频率。内容偏差是

```
p' = p + B p (1-p)
```

从众是

```
p' = p + D p (1-p) (2p-1)
```

三个榜样时系数落在 `-2 < D < 1`。`D = 0` 时频率不动。`D > 0` 离开 1/2，`D < 0` 走向 1/2。把从众映射在 1/2 处求导，得到 `f'(1/2) = 1 + D/2`。

在单个频率上，令 `B = D (2p-1)`，两张映射的第一步相同。之后从众的因子 `(2p-1)` 跟着 `p` 变，内容偏差的 `B` 不变，所以轨迹分开。

2026-10-24 在跑之前写下的数：`p0 = 0.7`，`D = -0.8`，`B = -0.32`，迭代 40 步。第一步差小于 `1e-12`。第二步内容偏差下降的幅度更大。40 步后内容偏差的频率低于推导出的上界 0.02，反从众的频率保持在 1/2 之上、`p0` 之下，两者之差大于 0.48。另有两条符号：`B = 0.5` 时 0.4 和 0.6 都上升；`D = 0.5` 时 0.6 上升、0.4 下降。

探针结果与这些判定一致。第一步两边都是 0.6328。第二步下降幅度是 0.0743565 和 0.0493727。40 步后内容偏差频率是 `7.80807e-07`，反从众频率印成 0.5，差是 0.499999。`D = 0.5` 时数值导数是 1.25，等于 `1 + D/2`。从 0.6 和 0.4 出发的从众步长是 +0.024 和 -0.024，内容偏差两边都是 +0.12。阈值没有改。

因此 `mechanism=attraction` 只说明这一张快照里子本彼此更近。它不说明存在一个内容吸引子，也不说明种群在从众。`contentBiasStep` 和 `conformityStep` 写在 `replica_trace.hpp`。进化开关仍关着：从众会把当前多数变体固定下来，而多数变体可以不是父本的复制。自我进化要等一条频率序列，以及那个外部公开分，才能把选择和这两种传递分开。

闭式上面还有一层个体规则，Denton 等的公式 (2)，`n = 3`。三个榜样独立抽取，其中 `j` 个是变体 A。`D(0) = D(3) = 0`，`D(2) = v`，`D(1) = -v`，采纳概率是 `j/3 + D(j)/3`。抽样程序不调用 `conformityStep`。

2026-10-24 事先写下的判定：`p = 0.7`，`v = 0.5`，20 万个子代，频率与闭式相差小于 0.005。`v = 0.8`、8000 人、15 代，频率高于 0.9，并且与闭式轨迹相差小于 0.05。`v = -0.8`、40 代，频率落在 `(0.35, 0.65)`，同样与闭式相差小于 0.05。种子是 20261024。

结果：一代的样本频率是 0.741765，闭式是 0.742。从众走到 1，闭式也是 1。反从众走到 0.491625，闭式是 0.5。判定成立，边界没有改。

## 五百组，按复制子而不是按词集合

一组实验同时做两件事。文本是六个互不相同、每个至少四个字母的词。父本是这个句子，另一个变体是同样的词倒过来。判定用 `judgeCopy` 的连续词段。倒序句的词类型交集是 1，这不算通过。

每一组在抽样之前还要满足：父本有 6 个词并且复制自己；倒序句有 6 个词、交集为 1、不是复制子；父本只有一个载体时不收录，第二个不同载体才收录；倒序句被观察两次也不收录父本；倒序句自己的两个不同载体才收录倒序句。

传递是三个榜样的个体规则，`D(2) = v`，`D(1) = -v`。每组 4000 个子代。频率格点是 `p = 0.20 + a * 0.025`（`a = 0..24`）和 `v = -1.20 + b * 0.10`（`b = 0..19`），共 500 组。采纳概率都落在开区间 `(0, 1)`。抽样不调用闭式。通过条件是样本频率与闭式的差不超过 5 倍标准误。存成父本的子代必须是父本的复制子，存成倒序句的子代必须不是。种子是 `20261024 + 组号`。

500 组全部有效，结构检查 500，频率检查 500。最大标准化偏差 3.088，最大绝对差 0.0233，平均绝对差 0.00612。5 倍标准误的界限没有改。词类型交集没有被用来收录模因。

## 重复一个词抬不高“出现”

检索里常用饱和词频，避免同一词在一篇里重复就把排名抬上去。我们的 α 仍是 `tf/df`，没有这项饱和。这次没有去打开一篇新的检索论文来改公式，只检验现有的出现条件够不够。

2026-10-24 在跑之前写下的判定是：只把查询里一个词重复八次的文本，不算出现；按顺序带上查询里两个词的文本，算出现。若两条都成立，就不把 α 改成饱和词频。

四条文本里，`gamma delta epsilon` 的 mass 是 1.68，lift 超过出现门槛，顺序 τ 是 1，重叠 2，出现为真。八次 `gamma` 的重叠是 1，顺序是 0，出现为假。判定成立，α 保持 `tf/df`。这次没有改排序代码。

## 无歧义的文字载体

构造是正向。一个意图写成一句规范句：

```
ask <工具> about <四个词> end
```

工具只取 `math`、`search`、`research`、`replicate`。四个论元词和 `ask`、`about`、`end` 都不相同，每个词至少三个字母，这样 `judgeCopy` 的分词不会把它们丢掉。`end` 是终止符，短论元不会变成长论元的连续前缀。

两条不同的规范句如果都是 n 个词，最长公共连续词段最多 n−1，保真度最多 `(n−1)/n`。复制门槛是 `2^(-1/n)`。对 n≥2，`2^(-1/n) = exp(−ln2 / n)` 严格大于 `1 − (ln 2)/n`，而 `(n−1)/n = 1 − 1/n` 又严格小于 `1 − (ln 2)/n`，因为 `1 > ln 2`。所以两条不同的规范句互相都不是复制子。同一句被前后包住（前面加 `please`，后面加 `thanks`）时，整句仍是连续词段，保真度是 1，这是复制。

识别是这张映射的逆。收到的文本里，恰好有一个规范句是它的复制父本，才返回那个工具。一个都没有，或者同时有两个，都返回 `none`。不在目录里的新论元用同一条规则：文本里恰好有一段连续的 `ask <工具> about <四个非框架词> end`，才返回那个工具。点名工具、把词序倒过来、或者拿掉 `end`，都没有这段，结果是 `none`。

这不是模因收录。收录仍然要繁殖力和寿命。这里只解码一个意图。

2026-10-25 在跑之前把接受条件写成：n 从 2 到 48 都满足上面的不等式；160 条规范句两两都不是复制；倒序都不是父本的复制；论元被延长之后两个方向都不是复制；目录逆映射和免目录逆映射在 960 条上和标签一致；子串扫描不能作为识别器。子串扫描按 `math`、`search`、`research`、`replicate` 的顺序找第一次出现。`research` 里面含有 `search`。

探针 `PASS carrier-construct`。不等式失败 0 次。160 条两两碰撞 0，不同规范句之间测到的最高保真度 0.75。倒序复制 0。前缀延长复制 0。960 条上目录逆映射错误 0，免目录逆映射错误 0。提及句 160 条，子串扫描没有一条给出 `none`。`research` 的规范句 40 条，子串扫描全部认成了 `search`。门槛没有按结果改。

代码在 `replica_trace.hpp` 的 `constructCarrier`、`recognizeCarrier`、`recognizeConstructed`。现场工具路由没有改接这三支函数。审议模型的提示里也还没有这句规范句，所以现在的任务回复不会因为这张逆映射而被改道。

## 工具侧自己理解

上面的规范句是一种双方都已经在用的编码。工具模块不能要求 base 把回复写成这句。base 不是识别器，也不是构造器。识别器在工具侧。一句自由文本可以同时有几种读法；只要其中一种读法是在调用某个工具，工具侧就调用它。句子里出现工具的名字，本身不是一次调用。

上一轮读出没有接到路由上。在追踪它的输出之前，把原因写成：它认的是句式，不是调用。判定有两条，都不按结果改。一是在留出的规范句上，把 `end` 换成 `the` 之后，正确类 logit 的平均降幅大于把任意一个论元词换成 `the`。二是五条不含这套句式的普通请求，正确类概率的平均值低于 0.5。五条是：`calculate twelve times four`，`please look up the eigen threshold`，`investigate how limits are defined`，`delegate a helper to draft the examples section`，`the river is cold but work out twelve times four`。

追踪结果成立。换成 `the` 之后，正确类 logit 的平均降幅是：`end` 83.86，工具名 35.23，`ask` 11.02，`about` 8.39，论元词 2.70。五条普通请求的正确类概率平均是 0.200。其中四条被读成 `none`，概率接近 0。`delegate a helper to draft the examples section` 这一条被读成 `replicate`，概率是 1。平均值仍然低于 0.5。所以这条读出的主要信号是终止符和工具名，不是论元里的事情，也没有覆盖没有句式的请求。

## 自由句子上的工具侧读出

新的训练不再使用 `ask ... end`。一句文本可以有几种读法。某个工具的动作读法存在，这个工具就该触发。工具名字单独出现，或者请求动词只作为词典里的词出现，都不触发。训练动词和留出动词不重叠，论元也不重叠。读出用全部词状态的平均，阈值 0.5。损失里的正类权重只用训练集计算。
