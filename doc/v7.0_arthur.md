# Phoenix v7.0 "Arthur" upgrade notes

This release focuses on true-multimodal fusion, primal-sensation/instinct
integration, and a cleaner split between immutable system instructions and
dynamic memory-derived prompts.

## New modules

### 1. True-multimodal semantic units (`semantic_unit.{hpp,cpp}`)

- `phoenix::multimodal::SemanticUnit` is the basic storage unit for multimodal
  data.  It carries a `modality` (`Text`, `Image`, `Audio`, `Video`, `Sensor`,
  `Structured`), `content`, `semanticVector`, `confidence`, `modalWeights`,
  `metadata`, and a stable `id`.
- Helper functions provide modality string conversions, vector normalization,
  cosine similarity, random-projection-based dimension alignment, and three
  fusion modes (`fuseAdd`, `fuseMultiply`, `fuseAttention`).
- `SemanticMemory` stores units, fuses retrieved units on demand, and searches
  by cosine similarity.

Integration points:
- `modern_context_system.{hpp,cpp}`: `ContextEntry` now contains a
  `std::vector<SemanticUnit> semanticUnits`; `ModernContextManager` exposes
  `addSemanticUnit()` and a `semanticSearch()` overload for `SemanticUnit`.
  (`ContextBuilder` is not yet implemented.)
- `main_hub_parts/041_class_memegraph.inc`: `MemeGraph` currently includes
  `semantic_unit.hpp` but does not yet expose `SemanticUnit` attachment or
  semantic similarity search over the graph.

### 2. Primal sensation layer (`primal_sensation.{hpp,cpp}`)

- `phoenix::primal::SensationType` enumerates `Pain`, `Pleasure`, `Hunger`,
  `Temperature`, `Fatigue`, `Threat`, `SocialIsolation`, `Novelty`.
- `PrimalSensation` records `intensity` (0..1), `valence` (-1..1), `durationSec`,
  `source`, and `timestampMs`.
- `PrimalSensationEngine` maintains active sensations, decays them over time,
  and exposes `netValence()`, `netArousal()`, and `dominant()`.

### 3. Instinct / benefit-harm layer (`instinct.{hpp,cpp}`)

- `phoenix::instinct::InstinctType` enumerates `Survival`, `Exploration`,
  `Avoidance`, `Affiliation`, `Curiosity`.
- `Instinct` combines `activation`, `benefitWeight`, `harmWeight`, a target
  `SensationType`, and an `actionBias`.
- `InstinctEngine::evaluate()` performs the 趋利避害 (benefit-harm) calculation
  across current sensations and returns a `BenefitHarmResult` with
  `benefitScore`, `harmScore`, `netUtility`, `recommendedAction`, and an
  8-dimensional emotion operation weight vector produced by a fixed linear
  matrix over `[benefitScore, harmScore, netUtility, abs(netUtility), activation]`.
  The vector is not an explicit emotion state; it is a set of latent weights
  that downstream modules (e.g. `EmotionVocabWeightTable` / logit-bias matrices)
  apply to matrices.
- `InstinctEngine::update()` implements dynamic activation regulation:
  current activation = base activation × (1 + sensation score) × time-decay.
  `evaluate()` and `evaluateAction()` use this runtime activation.
- `driveToEmotion()` converts the 8 operation weights into an `emotion::EmotionTensor`
  signal, keeping the mapping numeric and matrix-oriented rather than explicit
  behavior or words.

Integration points:
- `autonomy_stack.{hpp,cpp}`: `CognitionAutonomyManager` owns a
  `PrimalSensationEngine`, an `InstinctEngine`, and API methods
  `ingestSensation()`, `evaluateInstincts()`, and `composePrompt()`.
- `observe()` accepts `sensation` and `mixedModalPacket` payloads.
- `iterate()` calls `InstinctEngine::update()` with elapsed time, then
  recomputes benefit-harm and rebuilds the dynamic memory prompt each turn.

### 4. Prompt split (`prompt_split.{hpp,cpp}`)

- `SystemPrompt` is immutable: `identity`, `version`, `constraints`, and
  `coreDirective`.
- `MemoryPrompt` is dynamic: `summary`, `relevantFacts`, `activeGoals`,
  `emotionalTone`, and `benefitHarmBias`.
- `PromptComposer` combines system + memory + user prompts and can emit either
  a single text block or structured chat messages.
- `PromptComposer::fromContext()` and `fromSemanticMemory()` generate
  `MemoryPrompt` from recent context or semantic search results.

### 5. External mixed-modal I/O (`external_mixed_modal_io.{hpp,cpp}`)

- `MixedModalPacket` represents inbound/outbound mixed-modal packets with
  `id`, `modality`, `payload` bytes, `mimeType`, `source`, `timestampMs`, and
  `metadata`.
- `MixedModalInputBuffer` and `MixedModalOutputQueue` are thread-safe FIFOs for
  external data.
- `MixedModalChannelRegistry` tracks named external channels.
- `MixedModalPacket::toSemanticUnit()` delegates to `MixedModalConceptBridge`:
  text is encoded into a token or transformer concept vector, image/video prefer a
  JEPA world-model concept vector and fall back to patch-statistics, and audio
  uses a persistent speech-world-model alignment trained from audio-transcript
  pairs.  Every encoding result is passed through `PersistentConceptMatrix` for
  residual-based refinement and associative storage.
- `MixedModalConceptBridge::pretrainSpeech()` performs one JEPA adaptation step,
  speech-text contrastive alignment, and stores the paired acoustic and
  linguistic concepts in the persistent `PersistentConceptMatrix`.
- `MixedModalConceptBridge::pretrainImage()` performs one JEPA image adaptation
  step and stores the visual concept in `PersistentConceptMatrix`; an optional
  caption is also encoded and stored as an associated text concept.
- `MixedModalConceptBridge::reset()` clears the persistent speech concept model
  and the `PersistentConceptMatrix`.
- `MixedModalConceptBridge::decode()` adapts abstract semantic units back into
  external packets; non-text targets carry concept data until a target modality
  decoder renders an entity.  Image decode falls back to a 1x1 PNG placeholder if
  no decoder is configured.

Integration points:
- `autonomy_stack.{hpp,cpp}`: `CognitionAutonomyManager` owns an input buffer,
  output queue, and channel registry, with `ingestMixedModalPacket()`,
  `pretrainSpeechConcept()`, `pretrainImageConcept()`, `emitMixedModalOutput()`,
  `drainMixedModalOutputs()`, and `reset()` methods.

## Build changes

- `compile.bat` and `compile_gtest.bat` now write the list of source files to
  a response file (`build\compile_sources.txt` and `build\gtest_all_sources.txt`)
  to avoid Windows command-line length limits as the v7.0 module list grows.
- `COMMON_SOURCES` in both scripts now includes:
  `semantic_unit.cpp`, `primal_sensation.cpp`, `instinct.cpp`,
  `prompt_split.cpp`, `external_mixed_modal_io.cpp`,
  `video_model.cpp`, `audio_model.cpp`,
  `model_deployment.cpp`, `rdk_x5_bpu.cpp`, `graph_diffusion_summarizer.cpp`,
  `hierarchical_memory.cpp`.

## Tests

New GTest suites added in `tests/gtest/unit/multimodal` and
`tests/gtest/unit/autonomy`:
- `test_semantic_unit.cpp` — semantic unit construction, JSON round-trip,
  cosine similarity, normalization, projection, fusion, and semantic memory.
- `test_primal_sensation.cpp` — sensation type conversions, engine decay,
  net valence/arousal, instinct engine benefit-harm evaluation, and JSON
  round-trip.
- `test_prompt_split.cpp` — system/memory prompt defaults, composition, message
  structure, and context-to-memory generation.
- `test_external_mixed_modal_io.cpp` — modality conversions, JSON round-trip,
  packet-to-semantic-unit translation, buffer/queue/channel behavior, invalid
  input fallback, world-model concept-vector precedence, persistent speech
  concept pretraining, JEPA image fallback encoding, `PersistentConceptMatrix`
  residual refinement, `pretrainImage` with/without caption, `reset` behavior,
  semantic-unit decoding to text and non-text packets, and structured/sensor
  media concept encoding.
- `test_autonomy_stack.cpp` — `CognitionAutonomyManager` mixed-modal API
  coverage: `ingestMixedModalPacket()`, `pretrainSpeechConcept()`,
  `emitMixedModalOutput()`, and `drainMixedModalOutputs()` with both success
  and error paths.

## Configuration

- `config/phoenix_tuned.json` holds runtime-tuned context-window and
  affect/memebarrier parameters; `runtime_tuned_config.hpp` provides thread-safe
  JSON override access.

## API surface

Existing Drogon routes remain unchanged; v7.0 capabilities are consumed through
`CognitionAutonomyManager` via JSON payloads:
- `observe({ "sensation": { ... }, "mixedModalPacket": { ... } })`
- `evaluateInstincts()`
- `composePrompt({ "userPrompt": "...", "includeMemory": true })`
- `ingestMixedModalPacket({ ... })`
- `pretrainSpeechConcept({ "audio": { ... }, "transcript": "..." })`
- `pretrainImageConcept({ "image": { ... }, "caption": "..." })`
- `emitMixedModalOutput({ "semanticUnit": { ... }, "targetModality": "text" })`
- `drainMixedModalOutputs({ "max": 0 })`
- `reset()`
