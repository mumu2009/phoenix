# 模因论：定义、公式与证明

写于 2026-10-26。这份文件把已经接进代码的公式写成一套封闭的陈述：定义、判定、
映射、定理与证明。数值结果和探针在 `papers/transmission.md`；预注册切线在
`protocols_2026-10-26.md`；论文索引在 `papers.json`。这里只写能被代码引用的
东西，不把“叫做模因”当成“具有复制子性质”。

记号：载体是一段文本；`tok(x)` 是按 `judgeCopy` 的分词（字母数字、长度 ≥3、
小写）得到的词序列；`|x|` 是 `tok(x)` 的长度；`type(x)` 是 `tok(x)` 的词类型
集合；`1[·]` 是示性函数。所有频率都在单纯形
`Δ_{n-1} = {p ∈ R^n : p_i ≥ 0, Σ p_i = 1}` 上。`f` 是适应度因子（正数），
`f_i = ln w_i` 是增长率。

## 0. 模因的操作定义（判定树与共同因变量）

**定义 0.1（模因）**。一段文字 `p` 成为**模因**，当且仅当以下三个条件按序
全部成立；每一步都是一个可计算谓词，括号内是实现位置：

1. **复制子判定**：存在后来的载体 `o` 使 `o` 是 `p` 的复制子，即
   `fidelity(p,o) = span(p,o)/|p| ≥ σ^(-1/|p|)`，σ=2（§2.2，`judgeCopy`）。
2. **谱系准入**：在相继载体上的观察满足 `fecundity ≥ 2 且 longevity ≥ 2`
   （§3.2，`lineageObserve` + `admitted`）。
3. **传播力归属**：`p` 所在固定人口的代际频率序列经 `identifyForce` 落在
   fixed / content / conformity / replicator 之一且残差 ≤ 0.01（§14.3），
   或该序列是 undetermined——此时 `p` 仍是被判定的复制子，只是力的归属
   不可识别（§14 是力识别性的数学边界，不是模因判定的边界）。

**判定树**（任何一段候选文本按此走一遍，输出一个模因记录）：

```
候选文本 p
 └─ 有后来的载体 o 使 fidelity(p,o) ≥ 2^(-1/|p|)？
     ├─ 否 → 不是复制子（若 indexOverlap ≥ 1/2 记 indexWithoutCopy）
     └─ 是 → 复制子
          └─ 谱系观察 fecundity ≥ 2 且 longevity ≥ 2？
              ├─ 否 → 复制子，未准入（一次回声）
              └─ 是 → 准入模因
                   └─ 固定人口的代际频率序列 identifyForce：
                       fixed / content / conformity / replicator / undetermined
                       （力名 + 系数 + 残差 一并记入模因记录）
```

**共同因变量（三块工作挂在同一个量上）**。每个载体的**模因记录**是一个
元组：

```
memeRecord(p) = ( replicator ∈ {0,1},
                  fidelity,
                  admitted ∈ {0,1},
                  forceName ∈ {fixed, content, conformity, replicator,
                               undetermined},
                  forceCoefficient,
                  route ∈ {文件路径, ∅} × margin )
```

- 第 2–3 节（复制子判定 + 谱系准入）填前四个字段；
- 第 5–9、14 节（传播力识别）填 forceName / forceCoefficient；
- 第 10–11、17–18 节（开放列路由）填 route：这是模因的**操作化入口**
  （描述 → 载体档案 → 索引权重 → 路径），是工程应用案例，不是力的
  第三个来源。它回答“一个查询命中的模因档案是哪个”，不改变前六个字段。

同一个 `p` 的三个实验（复制子探针、力探针、路由探针）因此是在读同一个
模因记录的不同字段，而不是三个互相无关的量。若一个实验只做开放列，它
只证明入口正确，不声称传播力；反过来力探针不声称索引。

**模因存在的状态表（充分必要条件，逐字段的键见括号）**。`memeRecord(p)` 只是
诊断记录的 schema，不是模因的判定；判定按这张表：

| 字段 | 键（作用域） | 参与存在判定？ | 状态 |
| --- | --- | --- | --- |
| replicator | 父本—子本对 (p,o) | **是** | 1 ⇔ 存在子本 o：`fidelity(p,o) ≥ 2^(-1/\|p\|)`（§2.2） |
| fidelity | 父本—子本对 (p,o) | 诊断量 | 同一对 (p,o) 的值 |
| admitted | 谱系（p 及其相继载体） | **是** | 1 ⇔ `fecundity ≥ 2 ∧ longevity ≥ 2`（§3.2） |
| forceName | 种群代际序列 | **否** | 诊断量；fixed/content/conformity/replicator/undetermined 都**不**改变存在判定 |
| forceCoefficient | 种群代际序列 | 否 | 诊断量 |
| route | 查询→档案 | **否** | 入口/应用案例，明确不参与存在判定 |

**模因（定义 0.2）**：`p 是模因 ⇔ replicator(p)=1 ∧ admitted(p)=1`。
`forceName` 是诊断量不是条件：`undetermined` 的已准入复制子仍是模因（§14
只是说它的传播力不可从单一频率序列识别）；`forceName=fixed` 也不是排除
条件（无传播的模因仍是模因——复制与准入成立即可）。`route` 从不参与。
因此"文字载体上的模因"的判定与诊断完全分离：存在 = 复制子 ∧ 准入，
诊断 = 力名/系数/路由。

**符号表（全文唯一，消除 q/L 歧义）**：

```
q_copy   = 定义 2.1 的保真度（单次复制保住的 token 比例；§2.2 的复制地板用这个）
q_edit   = 源码编辑占全部拍的比例。账本把它写入名为 fidelity 的字段，
           并作为 eigenMasterLength 的第一个参数（§8）
L_parent = 父本的 token 长度（§2.2 的阈值指数）
L_max(q) = ln σ / (-ln q)，0 < q < 1，σ > 1
L_max^copy    = L_max(q_copy)，复制地板用的主序列长度上界
L_max^ledger  = L_max(q_edit)，账本 eigenLmax 的自变量；q_edit ≥ 1 时函数返回 1e9
σ        = 2（复制优势常数，§2.2）
```

## 1. 索引不是复制子

**定义 1.1（索引）**。对载体集合 `M` 和词 `w`，令 `tf(w,m)` 是 `w` 在载体 `m`
里的出现次数，`df(w) = |{m : tf(w,m) > 0}|`。索引权重是

```
α(w|m) = tf(w,m) / df(w).
```

一个查询 `q` 对载体 `m` 的索引质量 `mass(q,m)` 由 `scoreOrderedMemes` 给出：
查询词的预算按条件化种子分配到它命中的载体上，再用 collection-IDF 缩放；`lift`
是 `mass` 与“只保留高 df 词时的同一分配”的比；`overlap` 是查询与载体的公共
词类型数；`orderLift` 是查询词在载体里的 Kendall τ。

**命题 1.2（α 不是被复制的东西）**。`α` 依赖 `df`，而 `df` 依赖整个集合 `M`。
同一句被复制进 `M` 之后，`df` 和 `mass` 都可能改变，因此 `(w, α)` 这组权重不是
在相继复制中保住结构的那个实体。

*证明*。`α(w|m)` 的分子只依赖单个载体，分母 `df(w)` 依赖 `M`。取两个集合
`M ⊂ M'`，同一个 `m` 和 `w`：若 `w` 在 `M'\M` 里也出现，则 `df_M'(w) > df_M(w)`，
于是 `α_M'(w|m) < α_M(w|m)`。被保住的文本没有变，权重变了。按 Hull 1988 的
定义（复制子是在相继复制中保住结构的实体），权重集合不满足。∎

**命题 1.3（rankLatentEdit 的资格与选择）**。设文件档案为 `F`，描述为 `d`。
资格集合 `E = {f ∈ F : mass(d,f) > 0, lift(d,f) ≥ 2, overlap(d,f) ≥ 2}`。若 `E`
为空，路径为空。若 `E` 中 `mass` 的唯一最大者是 `f*`，路径为 `f*`，与词序无关。
若 `mass` 在 `E` 的最大值上不唯一，则只有在这种情况下才看 fecundity：当
fecundity 向量与 `F` 等长、恰有一个档案在并列者中 fecundity 严格最高、且该值
大于 0 时选它；否则路径为空。

*证明*。这是 `rankLatentEdit`（`memetic_existence.hpp`）的分支逐条重述：
第一个循环只把满足三个不等式的档案计入 `presentCount`；`best/second` 只按
`mass` 比较；`best->mass > second->mass` 时直接返回 `best`；相等时进入
fecundity 分支，`ties == 1 && topF > 0` 才返回。词序 `orderLift` 不在资格里，
因为构想不是源码的复制（`papers/transmission.md` 的 `latent-edit` 一节）。
∎

**推论 1.4（词序不是否决）**。一个档案的 `orderLift ≤ 0` 仍可被选中，只要它的
`mass` 严格最大。这解释了 2026-10-25 的 `emotion_system.cpp`：`instinct.cpp`
的 `mass = 0.052` 只是因为词序为正成为唯一 `present`，改成按 `mass` 取唯一最大
之后选中的是 `emotion_system.cpp`。旧 `present` 不是选择条件。

**命题 1.5（重复词不抬高 mass）**。把一个只在一个档案里出现的词在查询里重复
`k` 次，`mass` 不变。

*证明*。该词的命中列表只有一个档案，份额归一成 1，贡献等于查询里这个词的
质量；`mappingAddConditionedSeeds` 按查询词的总质量分配预算，重复只是把同一份
预算写成多份，总和不变。探针 `repetition-not-present` 在八次重复上验证：
`overlap = 1`、`orderLift = 0`、`present = false`。∎

## 2. 复制子的判定

**定义 2.1（保真度）**。对父本 `p` 和子本 `o`，

```
span(p,o)   = 最长的连续 token 段，它在 p 和 o 里都出现；
fidelity(p,o) = span(p,o) / |p|；
indexOverlap(p,o) = |type(p) ∩ type(o)| / |type(p)|.
```

**定义 2.2（复制子）**。令 `σ > 1`。当 `|p| ≥ 2` 且

```
fidelity(p,o) ≥ σ^(-1/L),   L = |p|,  σ = 2
```

时，称 `o` 是 `p` 的复制子（`replicator = true`）。若
`indexOverlap ≥ 1/2` 但复制子检验失败，记 `indexWithoutCopy = true`。

**定理 2.3（Eigen 阈值的一次复制形式）**。设父本长度 `L`，每个 token 的保真
概率为 `q`，主序列要在误差猫爪下维持，需要 `q^L σ > 1`，即
`L < ln σ / (-ln q)`。取 `q` 为“这一步保住的 token 比例”即 `fidelity`，则在
`σ = 2` 时阈值是 `2^(-1/L)`。

*证明*。Eigen 1971 的主序列条件：突变率 `1-q` 下，主序列的相对增长率是
`q^L σ`；它为正且大于 1 才不被误差猫爪吞掉。对一次复制，`q` 取这一步的保真
比例，条件 `q^L σ > 1` 等价于 `q > σ^(-1/L)`。`replica_trace.hpp` 的
`judgeCopy` 直接计算 `fidelity >= pow(sigma, -1.0/L)`。∎

**定理 2.4（不同的规范句互不复制）**。规范句是
`ask <tool> about <四个词> end`。两条不同的规范句长度都是 `n`，它们的最长公共
连续词段至多 `n-1`，因此保真度至多 `(n-1)/n`；而复制阈值
`2^(-1/n) = exp(-ln2/n) > 1 - (ln2)/n > 1 - 1/n = (n-1)/n`。所以两条不同的规范句
互相都不是复制子。

*证明*。`end` 是终止符，短论元不是长论元的连续前缀；两条句子若共享整段 `n` 个
token 就必须逐词相同（框架词相同、工具相同、四个论元按序相同），矛盾。故公共
连续段 ≤ `n-1`。不等式链：`exp(-x) > 1-x` 对 `x>0`；取 `x = (ln2)/n` 得
`2^(-1/n) > 1-(ln2)/n`；又 `ln2 < 1` 得 `1-(ln2)/n > 1-1/n`。探针
`carrier-construct` 在 `n=2..48` 上失败 0 次，最高保真度 0.75。∎

**命题 2.5（前后包裹仍是复制）**。若 `o` 含有 `p` 的整段连续 token（前面或
后面加词），则 `fidelity = 1`，`o` 是 `p` 的复制子。

*证明*。`p` 的全部 token 是 `o` 的一个连续词段，`span = |p|`。∎

**命题 2.6（倒序不是复制）**。把 `p` 的词序倒过来得到的文本，`indexOverlap = 1`
但保真度低于阈值（长度 ≥2 时），所以 `indexWithoutCopy = true`。

*证明*。`type` 相同所以交集为 1；`p` 与倒序的最长公共连续段在 `p` 有至少两个
不同词时只能是 1（相邻对不再相同），`1/L < 2^(-1/L)`（对 `L≥2`）。∎

## 3. 谱系：保真度、繁殖力、寿命

**定义 3.1（谱系状态）**。`LineageState{fecundity, longevity, streak}`。每次
观察一个后来的载体：

- 若它是复制子：`streak += 1`，`longevity = max(longevity, streak+1)`，若载体
  不同则 `fecundity += 1`；
- 若它是 `indexWithoutCopy`：`streak = 0`；
- 无关文本不改变状态。

**定义 3.2（准入）**。`admitted = (fecundity ≥ 2) 且 (longevity ≥ 2)`。

**命题 3.3（一次回声不是模因）**。单个载体复制父本一次，`fecundity = 1`，
不满足准入。

*证明*。定义 3.1 只在不同载体上增加 `fecundity`；一次复制至多 `fecundity=1`。
∎

**命题 3.4（索引重合结束连续复制，但不清寿命）**。`indexWithoutCopy` 把
`streak` 清零，不改变 `longevity` 和 `fecundity`；无关文本三项都不动。

*证明*。`lineageObserve` 的三个分支。注意“毫不相干的文本不是这一支的一代”，
所以不是复制子也不是 `indexWithoutCopy` 的文本不结束连续复制。∎

**命题 3.5（寿命是最长寿命）**。`longevity` 是父本加上当前连续复制串的最长
长度，后续清零不降低它。

*证明*。`longevity` 只被 `max` 更新，`streak=0` 不写 `longevity`。∎

## 4. 群体标签

**定义 4.1（吸引偏差）**。对父本 `p` 和子本 `o_1..o_k`：

```
parentFidelity   = (1/k) Σ_i fidelity(p,o_i)
internalFidelity = (1/(k(k-1))) Σ_{i≠j} fidelity(o_i,o_j)
attractionBias   = internalFidelity - parentFidelity
parentCopies     = #{i : o_i 是 p 的复制子}
peerCopies       = #{(i,j) : i≠j, o_i 是 o_j 的复制子}
```

**定义 4.2（群体标签，2026-10-24 预注册）**：

```
replication  : parentCopies ≥ 1 且 attractionBias ≤ 0
attraction   : parentCopies == 0 且 peerCopies ≥ 1 且 attractionBias > 0
undetermined : 其余
```

**命题 4.3（标签不是准入）**。标签不改变 `LineageState`，也不调用
`lineageAdmitted`。

*证明*。`classifyPopulation` 只读 `PopulationRelation` 的计数与偏差，返回字符串；
`relatePopulation` 把它写进 `mechanism`。没有任何一条路径写 `fecundity` 或
`longevity`。∎

**命题 4.4（复制 + 正偏差是未定）**。若 `parentCopies ≥ 1` 且
`attractionBias > 0`，标签是 `undetermined`，不是 `replication`。

*证明*。定义 4.2 第一条要求偏差 ≤0；第二条要求 `parentCopies==0`。两条都不满足。∎

**命题 4.5（倒序句的谱系独立）**。两份相同的倒序句彼此复制，标签是
`attraction`；被收进记忆的是倒序句自己的谱系，原句的谱系不因此被收。

*证明*。原句对倒序的 `parentCopies=0`、倒序对倒序 `peerCopies≥1`、偏差
`=1-0.25>0`；准入只作用于“哪一条谱系被观察”，观察对象是倒序句。∎

## 5. 传播力：内容偏差与从众

**定义 5.1（Boyd–Richerson 映射，按 Denton 等 2020 式 (1)）**。`p` 是变体 A 的
频率：

```
content:    p' = p + B p (1-p)
conformity: p' = p + D p (1-p) (2p-1),  -2 < D < 1（三个榜样）
```

**命题 5.2（一步不可识别）**。在单个频率上，令 `B = D(2p-1)`，两张映射的第一
步相同。

*证明*。把 `B` 代入内容偏差：`p + D(2p-1)p(1-p) = p + D p(1-p)(2p-1)`。∎

**命题 5.3（两步可识别，条件）**。设 `p_0, p_1, p_2 ∈ (0,1)`，`p_0 ≠ 1/2`。
令

```
B = (p_1-p_0) / (p_0(1-p_0))
D = (p_1-p_0) / (p_0(1-p_0)(2p_0-1))
ŵ = p_1(1-p_0) / (p_0(1-p_1))
```

则在三张映射各自的第一步拟合下，第二步的预测是

```
content:    p_2^B = p_1 + B p_1(1-p_1)
conformity: p_2^D = p_1 + D p_1(1-p_1)(2p_1-1)
replicator: p_2^w = p_1 ŵ / (p_1 ŵ + 1 - p_1)
```

若其中一张的绝对残差 ≤ ε、且与亚军的差 > δ，就把序列判给那张；否则
`undetermined`。

*证明*。第一步拟合是代数反解；预测是把参数代回第二步。可识别性不是“总有唯一
答案”，而是“残差有个可检查的分离”；当 `B=D=0` 或 `p_0=1/2` 时分离失败，
规则如实返回 `undetermined`。∎

**命题 5.4（内容偏差没有内点不动点）**。`B ≠ 0` 时，`content` 在 `(0,1)` 内
没有不动点；`B>0` 时频率上升，`B<0` 时下降。

*证明*。`p' = p` 当且仅当 `B p(1-p)=0`，在 `(0,1)` 上只有 `B=0`。符号由
`B p(1-p)` 决定。∎

**命题 5.5（从众的稳定性）**。`conformity` 在 `1/2` 处的导数是
`f'(1/2) = 1 + D/2`。`D>0` 时离开 `1/2`（不稳定），`D<0` 时走向 `1/2`（稳定）。

*证明*。对 `f(p)=p+Dp(1-p)(2p-1)` 求导：
`f'(p) = 1 + D[(1-2p)(2p-1) + p(1-p)·2]`。在 `p=1/2`：
`(1-2p)=0`，`p(1-p)=1/4`，故 `f'(1/2)=1+D·2·1/4=1+D/2`。`|f'|<1` 当且仅当
`-1 < 1+D/2 < 1`，即 `-4<D<0`；结合 `-2<D<1` 得 `D<0`。∎

**命题 5.6（一步相同的两条轨迹会分开）**。若 `B = D(2p_0-1)` 且 `D≠0`，
则 `p_1` 相同，但 `p_2` 一般不同；差的符号由 `D` 和 `p_1-1/2` 决定。

*证明*。第二步差：
`p_2^D - p_2^B = D p_1(1-p_1)[(2p_1-1)-(2p_0-1)] = 2D p_1(1-p_1)(p_1-p_0)`。
只要 `p_1≠p_0`（即 `D(2p_0-1)≠0`）且 `D≠0`，差非零。∎

## 6. 连续复制子方程

**定义 6.1（Nowak 方程）**。对变体频率 `p ∈ Δ` 和常数适应度 `f_i`：

```
dp_i/dt = p_i (f_i - f̄),   f̄ = Σ_j p_j f_j.
```

**定理 6.2（解）**。初值 `p(0)` 的解是

```
p_i(t) = p_i(0) e^{f_i t} / Σ_j p_j(0) e^{f_j t}.        (R1)
```

*证明*。令 `q_i(t) = p_i(t) e^{-f_i t}`。则
`q_i' = e^{-f_i t}(p_i' - f_i p_i) = -f̄ q_i`，故
`q_i(t) = q_i(0) exp(-∫_0^t f̄)`。代回
`p_i(t)=q_i(t)e^{f_i t}`，公共因子 `exp(-∫ f̄)` 在归一化中消去，得 (R1)。
`Σ_i p_i(t) = 1` 对任意 `t` 成立；`p_i(0)=0` 时 `p_i(t)=0`。∎

**定理 6.3（平均适应度单调，Fisher 基本定理）**。

```
d f̄/dt = Σ_i p_i (f_i - f̄)^2 = Var_p(f) ≥ 0,
```

等号当且仅当所有支撑上的 `f_i` 相等。

*证明*。`d f̄/dt = Σ_i f_i p_i' = Σ_i f_i p_i(f_i-f̄)
= Σ_i p_i(f_i-f̄)^2`，最后一个等号因为 `Σ_i p_i(f_i-f̄)=0`。∎

**定理 6.4（离散映射是单位时间流）**。离散映射
`p'_i = p_i w_i / Σ_j p_j w_j` 等于 (R1) 在 `t=1`、`f_i = ln w_i` 的取值。

*证明*。`e^{f_i·1} = w_i`；代入 (R1) 即得。∎

**推论 6.5（召回里按 fecundity × longevity 排序就是单位时间流的名次）**。把
`w_i = fecundity_i · longevity_i` 代入定理 6.4，`t=1` 的 flow 份额与
`w_i` 成正比；份额的排序与 `w_i` 的排序相同。因此离散的名次不是另一套模型，
而是连续方程在单位时间的静态解。现场 `saveAliases` 计算并记录这个 flow，
`orderEqual=1` 是这条推论的数值检查。

**命题 6.6（recall 的离散一步）**。频率 `p`、适应度 `w`，一步后的频率是
`p_i w_i / Σ p_j w_j`；总权重非正时频率不动。

*证明*。`replicatorStep` 的定义；`mass ≤ 0` 时返回输入。∎

## 7. Price 方程

**定理 7.1（Price 1970；El Mouden 等 2014）**。

```
Δz̄ = cov(c, z)/mean(c) + E(Δz),
```

`c` 是文化适应度，`z` 是性状（这里 `z=1` 表示这一拍是源码编辑），`E(Δz)` 是
传递项。

**定理 7.2（原样复制时复制子映射与 Price 选择项相同）**。若每个父本把自己的
性状原样复制，初始频率均匀，则

```
mean(z)' - mean(z) = cov(c,z) / mean(c).
```

*证明*。`mean(z)' = Σ_i p'_i z_i`，`p'_i = c_i / Σ_j c_j`（均匀初值
`p_i=1/n` 约去）。`mean(z) = (1/n)Σ z_i`。两边相减并整理得
`[Σ c_i z_i / Σ c_j] - (1/n)Σ z_i = cov(c,z)/mean(c)`。数值例：`c=(1,3)`、
`z=(0,1)` 得 0.25；`c=(1,1)` 得 0；实例账本全体 `c=1` 时选择项为 0。
∎

**推论 7.3**。`replicatorStep` 与 `faithfulMeanShift` 在均匀初值、原样复制下
是同一个数；用 `priceSelectionOf(fecundity, admitted)` 在别名保存时记账，
全体 `c=1` 的实例账本不改。

## 8. 误差阈值

**定义 8.1**。`σ > 1`，`0 < q < 1` 时

```
L_max(q) = ln(σ) / (-ln q).
```

`L_max^copy = L_max(q_copy)` 是复制地板对应的主序列长度上界。
`L_max^ledger = L_max(q_edit)` 是账本上的长度：`accountReplicas` 先把
`fidelity = sourceEdits / ticks`，再调用 `eigenMasterLength(fidelity, sigma)`。
`q = 0` 时返回 `0`。`q ≥ 1` 时上界无意义，代码返回 `1e9`。这两个值不是同一个数。

*证明*。定理 2.3 的 `q^L σ > 1` 两边取对数：
`L ln q + ln σ > 0`。`ln q < 0`，故 `L < ln σ / (-ln q)`。∎

**命题 8.2（Lmax 不是类别编号的函数）**。32 路标签的分类准确率既不是
`q_copy` 也不是 `q_edit`。把 `Lmax` 用到类别编号上没有得到证明的映射。

*证明*。类别编号是闭集输出层的下标，不是相继复制中保住的结构，也不是
源码编辑所占的拍数比例。二者没有已知的等式。∎

## 9. 传播体制（Acerbi 等 2021）

**定义 9.1（体制切线，2026-10-24 写定）**。对逐步保真度序列
`f_1..f_T`（`T≥6`），

copying:     前半段 ≥0.75 且后半段 ≥0.75

**命题 9.3（接到谱系上只作顾问标签）**。`lineageRegime` 把谱系的相邻载体逐个

## 10. 一次外积与开放列

**定理 10.1（一次外积的分数）**。把词看成冻结的 one-hot，第二层是 `W`。见证一对
`(x,y)` 时做 `W ← W + y x^T`。只有一次更新、且词不重复时，
`score(q,f) = |q ∩ x| · |f ∩ y|`。

*证明*。`score = f^T W q = f^T (y x^T) q = (f^T y)(x^T q)`；one-hot 下
`f^T y = |f∩y|`，`x^T q = |q∩x|`（这里 `x,y,q,f` 是词集合的示性向量）。∎

**定理 10.2（闭集没有新列）**。闭集 softmax 的输出支撑是训练时见过的类别；
没给过第四个文件的 logit，`argmax` 就不可能是它。

*证明*。`z = W h` 的列数等于 `W` 的列数，即类别数；新增文件没有列，`z` 的
下标集合不变，`argmax` 落在旧下标里。∎

**引理 10.3（一类时交叉熵梯度为 0）**。只有一个类别时，softmax 恒为 1；若目标
也是这个类别，梯度 `softmax - onehot = 0`。因此“打开第一列 + 一步交叉熵”不能把
第一列从 0 训练出来。

*证明*。`softmax_1(z)=1`；`dz = 1-1=0`。∎

**定理 10.4（开放列的一步）**。先补一个 0 列，再做一次交叉熵，新词袋可以指向
新列，旧词袋仍指向旧文件，没写过的词袋仍是平局。

*证明*。`openColumnMlp` 的 `openClass()` 追加 0 列；`step()` 的 `dz` 在目标列
为正（`1-softmax_target`），在其它列为负；`W` 的更新让目标列在新词袋上的
logit 上升。旧词袋的 `h` 不变，旧列权重只按 `-softmax·h` 略微下降，排序不变。
未写过的词袋 `h=0`，所有 logit 都是 0，`argmaxStrict` 返回 -1。∎

**定理 10.5（Hebbian 开放列写与阅读）**。路由器用 `W[c,i] += h_i` 作为一次写，
`route` 取严格最大且 `z>0` 的列。于是新文件的列在其自身词袋上的分数是
`|h|`，旧列在它上面是 0（忽略哈希碰撞）；相同词袋的两个文件得到相同的列向量，
`route` 返回空。

*证明*。`h` 是词袋的隐藏单元指示向量；新列只在 `h` 的支撑上加了 1，点积为
`Σ_i h_i^2 = |h|`；旧列没有在这些单元上加权重，点积为 0。相同词袋给出相同的
`h`，两列点积相等，`ties != 1` 返回 -1。∎

**定理 10.6（合取隐单元分开线性词袋分不开的情形）**。设两行的词袋相同，
一行写入了描述的四词连续段 `(a,b,c,d)`，另一行没有写入该段。任何形如
`score = Σ_w z_{r,w} x_w` 的线性词袋打分在两行上相同；加入隐单元
`h_{r,j} = 1[行 r 写入了第 j 个连续有序词段，且描述含有它]` 后，线性读出
`Σ_j v_j h_{r,j}` 可以取不同的值。

*证明*。令 `φ(x) = (1[x_w])_w` 是词袋示性向量，`z_r` 是行 `r` 的线性权重
（写入的词为 1）。两行写入同一组词，所以在描述上 `z_A·φ = z_B·φ`，线性打分
相同。连续段 `(a,b,c,d)` 的合取不是 `φ` 的线性函数：两行在描述上的 `φ` 相同，
但 `h_{A,(a,b,c,d)}=1`、`h_{B,(a,b,c,d)}=0`；一个只依赖 `φ` 的函数不可能在同一
输入上取两个值。加入合取单元后，读出在 `A`、`B` 上分别多出 `v_{abcd}` 和 0，
可以分开。具体实例见 `hidden_link_probe.cpp`：两行词袋 6/6、词对 3/3，隐层
6/4，选中第一行。∎

**命题 10.7（隐层只在平局后使用）**。`rankBlockedLinks` 的五段顺序是：词袋唯一
且 ≥2 → fecundity → 词对唯一且 ≥2 → 隐单元唯一 → 空。词袋已经唯一时，隐层不会
改选。

*证明*。前两段直接 return；第三段 `pairWinners==1` return；只有
`pairWinners != 1` 才进入隐层，且要求 `hiddenBest > pairBest`。∎

## 11. 条件似然与两次命中

**定义 11.1（条件似然路径）**。冻结的因果模型给描述每个 token 打对数概率，
前缀是 `Notes about:` 加档案的最多八个特异词。`T = 0.2818081893704152` 是 17 个

**引理 11.2（一次命中不是证据）**。一次条件命中只把新词停在 pending；发布需要
第二次独立命中。

*证明*。`confirmCondWords` 在没有 `shared≥2` 且没有“两侧各至少 2 个”时只写
`pending`，返回 0。∎

**命题 11.3（重复不是第二次命中）**。若两次描述的内容词集 Jaccard ≥0.9，
第二次不发布，也不改动 pending。这与“两次命中”的语义一致：同一句话被老师判了
两次，仍然是一个观测。

*证明*。`condNearDuplicate` 定义；`confirmCondWords` 在入口返回 0。∎
（注意：探针里“只有一句话”的失败模式仍然存在：老师可以把同一句错话判对两次；
本命题只能消除“同一句被重复计两次”，不能消除“两个不同描述都被老师判错”。
后者需要外部真值，不在本理论能证明的范围内。）

**命题 11.4（发布后本地可路由）**。共享交集 ≥2 时，两次命中的描述都含这 ≥2 个
词；混合分支要求两侧各 ≥2，因此两次描述各自至少含 2 个被发布的词。于是两次
描述对同一档案的 `overlap ≥2`，不需要再调用 8107。

*证明*。`overlap` 的定义；词法排名只检查词是否在档案文本里。∎

**命题 11.5（老师缓存）**。同一个 `(描述, 档案词)` 第二次询问返回缓存的路径，
不再发起模型交换；缓存只存路径，上限 256 条。

*证明*。`condProfilePath` 在交换前查 `cache[line]`；命中直接返回。∎

## 12. 复杂度

- `judgeCopy`：`O(|p|·|o|)` 时间、`O(|o|)` 空间（连续段 DP）。

## 14. 力的可识别性边界（混合力不可分）

**定理 14.1（混合力的二维核）**。设
\[
\Delta p=p(1-p)\big[a+b\,p+d\,(p-\tfrac12)+r\big],
\]
则对任意 \((a,b,d,r)\)，
\[
\Delta p=p(1-p)\,(A+Bp),\qquad A=a+r-\tfrac d2,\quad B=b+d.
\]
映射 \((a,b,d,r)\mapsto(A,B)\) 是满射，核为
\(\{(a,b,d,r): a+r-d/2=0,\ b+d=0\}\)，维数 2。因此仅凭 \(p(t)\) 的序列，
四个力不能分别识别；能识别的只有两个组合。

*证明*。展开括号即得 \(A,B\) 的表达式。线性映射的秩为 2（例如取
\((a,b)=(A,B)\)、\(d=r=0\) 得到原像），秩-零化度定理给出核维数 4-2=2。∎

**定理 14.2（单一力的可识别参数）**。若真实过程只含一种力：
- 一次内容（直接偏差，§5 的 `contentBiasStep` 所用）：
  \(\Delta p=B\,p(1-p)\)，则 \(B=\Delta p/[p(1-p)]\)（\(0<p<1\)）；
- 二次内容（§14.1 的 `B p^2(1-p)` 项，与一次内容**不是**同一参数，勿互换）：
  \(\Delta p=b\,p^2(1-p)\)，则 \(b=\Delta p/[p^2(1-p)]\)（\(0<p<1\)）；
- 从众：\(\Delta p=d\,p(1-p)(p-\tfrac12)\)，则 \(d=\Delta p/[p(1-p)(p-\tfrac12)]\)
  （\(p\ne\tfrac12\)）；
- 复制子：\(\Delta p=r\,p(1-p)\)，则 \(r=\Delta p/[p(1-p)]\)；
- 固定：\(\Delta p=0\)。

*证明*。逐式代入并相除；分母非零的条件已在括号中给出。∎

**推论 14.3**。`identifyForce` 是四种单一力假设的**模型选择**，不是联合拟合。
它报告的是“哪一种单一力残差最小且与次小者分离”，所以混合力可能被标成某一种
单一力（探针里四点混合的残差 0.049 已经在 0.01 门外，被拒；但更接近单一力的
混合仍可能通过）。要真正分解混合力，需要频率依赖或多载体的实验设计，不在
\(p(t)\) 一条序列里。

## 15. 复制子流的收敛速率

**定理 15.1（常数适应度）**。设 \(w_i>0\) 常数，\(m=\arg\max_i w_i\)，
\(\rho=w_{(2)}/w_{(1)}<1\)（\(w_{(1)},w_{(2)}\) 是最大和次大）。则
\[
1-p_m(t)\le \Big(\sum_{i\ne m}\frac{p_i(0)}{p_m(0)}\Big)\rho^t .
\]
*证明*。\(p_i(t)/p_m(t)=(p_i(0)/p_m(0))(w_i/w_m)^t\le
(p_i(0)/p_m(0))\rho^t\)；对 \(i\ne m\) 求和并用
\(1-p_m\le\sum_{i\ne m}p_i/p_m\)（\(p_m\le1\)）即得。∎

**定理 15.2（频率依赖的 Lyapunov 函数）**。若存在势函数 \(F(p)\) 使
\(f_i(p)=\partial F/\partial p_i\)，则沿复制子流
\[
\frac{dF}{dt}=\sum_i p_i\big(f_i-\bar f\big)^2\ \ge 0,
\]
等号仅在所有被支撑的 \(i\) 的 \(f_i\) 相等时成立。因此 \(F\) 单调不减，轨道
收敛到 \(F\) 的稳定点（若 \(F\) 有上界）。

*证明*。\(dF/dt=\sum_i f_i\,dp_i/dt=\sum_i f_i p_i(f_i-\bar f)
=\sum_i p_i(f_i-\bar f)^2\)，因为 \(\sum_i p_i(f_i-\bar f)=0\)。∎

## 16. Price 协方差与连续流的一阶等价

**定理 16.1**。对常数性状 \(z_i\)（\(\Delta z_i=0\)），Price 方程
\(\Delta\bar z=\mathrm{Cov}(w,z)/\bar w\) 与连续流在 \(t=1\) 的 Euler 步
一阶相同；两者之差是 \(O\big((\max_i|w_i-\bar w|)^2\big)\)。

*证明*。连续流 \(d\bar z/dt=\sum_i z_i p_i(f_i-\bar f)
=\mathrm{Cov}(f,z)\)。Euler 步给出
\(\bar z+\mathrm{Cov}(f,z)\)。离散复制子
\(\bar z(1)=\sum_i z_i p_i w_i/\bar w
=\bar z+\mathrm{Cov}(w,z)/\bar w\)。把
\(p_i(1)=p_i[1+(w_i-\bar w)/\bar w]\) 代入并按
\((w_i-\bar w)/\bar w\) 展开，零阶与一阶项正好是 Price 的两项，余项是二阶。∎

**推论 16.2**。在常数适应度下，连续流和离散映射给出**同一个**排序；所以
`[flow] orderEqual=1` 是恒等式检查，不是额外的经验发现。要看到两者分离，
需要频率依赖的适应度或非 Euler 的时间步长。

## 17. 开放列的交叉熵一步（背景类修复零梯度）

**定理 17.1（一步下降）**。设损失 \(L(\theta)=-\log \mathrm{softmax}(o)_y\)，
\(\theta'=\theta-\eta\nabla L\)，\(L\) 是 \(L_L\)-光滑的。则
\[
L(\theta')\le L(\theta)-\eta\big(1-\tfrac{\eta L_L}{2}\big)\|\nabla L\|^2 .
\]
若 \(\nabla L\ne0\) 且 \(0<\eta<2/L_L\)，则严格下降。

*证明*。光滑函数的下降引理
\(L(\theta-\eta g)\le L(\theta)-\eta g^\top g+\tfrac{L_L\eta^2}{2}\|g\|^2\)，
取 \(g=\nabla L\)。∎

**定理 17.2（背景类使梯度非零）**。单类 softmax 有
\(\partial L/\partial o=\mathrm{softmax}(o)-\mathrm{onehot}(y)=0\)（因为
softmax=1）；加一个背景类后，对有限 logits，
\(\mathrm{softmax}_y\in(0,1)\)，故
\(\partial L/\partial o\ne0\)。若输出层 \(W\) 与隐层雅可比
\(\partial h/\partial V\) 非退化，则 \(\nabla_V L\ne0\)。

*证明*。链式法则
\(\nabla_V L=(\partial h/\partial V)^\top W^\top(\mathrm{softmax}-\mathrm{onehot})\)；
单类时括号为零；两类时其分量符号相反、不全为零。∎

## 18. 教师-学生路由的调用次数界

**设定**：学生路由器在得到某个文件的第一次教师标签后，用
(描述, 文件) 训练；对来自同一分布、间隔 \(\gamma>0\) 的描述，学生以至少
\(1-e^{-m\gamma^2/2}\) 的概率判对（\(m\) 是该文件的标签数；Hoeffding 界，
假设间隔有界）。

**定理 18.1**。每个文件的期望教师调用次数不超过
\[
1+N\,e^{-m\gamma^2/2},
\]
其中 \(N\) 是该文件上待路由的描述数。若学生在第一次标签后即达到间隔
\(\gamma\)，第二次描述起就以高概率本地路由。

*证明*。第一次标签是必需的（无监督时学生没有该文件的标签）；此后每个描述
独立地以不超过 \(e^{-m\gamma^2/2}\) 的概率判错，判错才回退到教师。期望的
回退次数由联合界给出。∎

**推论 18.2**。把学生放在教师**之前**（而不仅是之后回退）时，教师调用数
从“每个描述两次”降到“每个文件一次 + 错误回退”；这就是“快训”的可检验含义。
它不是零调用：第一个标签仍要教师，学生的错误率也不是零。
