# 2026-10-28g：从坏初代 64 开始的公平自主进化（G=8）

10.21/10.23 从 210 开始，发现公平 workMs 的最优在 ~190–210，初代已经没有
上升空间；10.23 从 186 也只能在 188–203 之间徘徊。要证明“自主进化让任务
提前结束”，需要一个**坏初代**。这里从 64 开始，其余装置同 10.21（父/子都
Granite、空起点、同 goal、plain/temp0、autoChildDoneChars=1200、λ=3、
`childFreshTask=true`、workMs 选择）。

**切线**：

1. 末代 adopted > 64（基因组向上爬）。
2. 末代 adopted 子盒的 workMs < 第 0 代被选中子盒的 workMs（77.745 的
   53,858）。
3. 用末代 adopted 在 Granite 空起点对 64 做 A/B（A B B A）：B 的回合数中位
   < A，且墙钟中位 < A。
4. 每代 3/3 自动判完成、无人工 `/child/done`；每代 adopted 的 workMs 严格
   最小（同模型空起点）。

**失败处理**：若 1 或 2 不成立，记录八代轨迹；若 3 只满足一条，记录两条并
说明哪个是噪声。

**结果（2026-10-28 21:03–21:33，G=8，λ=3）**：**切 1/2/4 PASS；切 3 待
A/B**。
