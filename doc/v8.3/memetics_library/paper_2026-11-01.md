# 文字载体何时是模因

匿名审稿稿。2026-11-01。

**关键词。** 模因；复制子；文化吸引；从众偏差；Price 方程；操作定义。

**本文贡献。**

1. 存在条件是：存在子本使复制子谓词成立，并且谱系准入成立。模因记录是按父本聚合的诊断视图，带证据层，不代替存在条件。
2. 繁殖力的“新来源”按调用点写死：词条谱系用原文字符串，跨上下文记忆用非空来源标记。
3. 人口取整的系数误差写成最坏上界。\(N=64\) 的从众失败保持为预注册结果；\(N=1024\) 是事后的探索性复算，输出已归档。
4. 稳定段规则同时用于两个模型，并保留无窗口结果。模型层的结论是输出不跟随注入值。短提示复述只说明另一种提示下标签可被写进回复。

## 摘要

父本文字 \(c\) 是模因，当且仅当存在子本 \(o\) 使 \(\mathrm{replicator}(c,o)=1\)，并且 \(\mathrm{admitted}(c)=1\)。前者是一对载体上的保真度地板。后者要求繁殖力至少为 2 且寿命至少为 2。繁殖力只在调用者认定的新来源上增加。词条谱系的来源是后来文本的原文字符串；跨上下文记忆的来源是非空的来源标记。一次回声只有一个来源，繁殖力为 1，不准入。

模因记录 \(\mathrm{memeRecord}(c)\) 把父本—子本对、谱系、人口频率和一次查询收成按 \(c\) 索引的诊断视图。力的名称和路由不进入存在条件。记录带 \(\mathrm{evidenceLayer}\)，取 model、calibration、route 之一，避免把标定层的 conformity 读成模型层的 conformity。力可以是 undetermined。已准入的复制子在力不可识别时仍是模因。

识别器的输入是送入它的频率序列。用第一点到第二点反解 \(B\)、\(D\) 和 \(w\)。配置起点不自动插到序列前面。在 \(p=0.4\) 处，半个箱宽造成的从众系数误差至多为 \((1/(2N))/0.048\)。这是最坏情况上界。\(N=64\) 时约为 0.163，大于切口 0.05，故该人口不能保证收回系数。预注册序列的实际误差是 0.215873，失败保留。\(N=1024\) 是看到这次失败之后的探索性检查，五臂按原切口通过，从众误差 0.00585182 低于约 0.010 的上界。折线 \(0.2,0.9,0.3\) 的内容残差是 0.99375，复制子残差是 0.696923，从众候选因 \(\lvert D\rvert\ge 2\) 使用哨兵残差 4。程序确定，没有置信区间。复算输出在 `bias_rule_recompute_2026-11-01.txt`。

模型层的结论是：输出不跟随注入值。稳定段规则下，Granite 的注入后缀是 fixed，Qwen 的注入后缀是 undetermined。无窗口的两条注入序列都是 undetermined。短提示复述只说明另一种提示下标签里的小数可以出现在回复中。原实验的回复正文没有归档，不能据此说原实验读到了标签。

路由只支持一次热进程正查询。冷启动未检验：正、负两个标签送进路由器的都是长度 74 的目标句。

## 1 引言

“模因”在文化演化文献里常常是一个名称。Edmonds（2005）指出，名称并不赋予复制子性质。Dawkins（1976）列出寿命、繁殖力与复制保真度，没有规定一段文字如何通过这三项。Sperber（1996）以及 Claidière、Scott-Phillips 与 Sperber（2014）把吸引写成一般过程，把保住结构的复制写成特例。El Mouden、André、Morin 与 Nettle（2014）用 Price 方程分开选择协方差和传递项。Henrich 与 Boyd（1998）、Henrich 与 McElreath（2003）把从众与内容偏差分开。缺的是一个可以在文本上执行、并且规定哪些字段参与存在判定的记录。

本文回答：一段文字在什么条件下是模因，哪些量只是诊断。第 3 节给出符号、存在条件、来源规则、索引资格和识别器。第 4 节报告标定复算、两个模型的注入频率，以及一次路由日志。第 5 节写明每条观测支持哪一句、不支持哪一句。

Dawkins 的三个因素在这里都有谓词。存在条件取“存在合格子本”与准入的合取。一次回声的繁殖力是 1。这比“模仿的单元”窄。

Henrich 与 Boyd（1998）的从众传递使采纳多数变体的概率高于该变体的频率。本文的从众映射允许 \(-2<D<1\)。\(D>0\) 离开 \(1/2\)，\(D<0\) 走向 \(1/2\)。后者是 Denton 等（2020）的反从众。本文没有声望偏置。

Boyd 与 Richerson（1985）指出引导变异和有偏传递在选择平坦时仍改变性状。Denton 等（2020）的式 (1) 是本文迭代的一次内容式与从众式。\(b\,p^{2}(1-p)\) 只出现在混合力的秩论证里。Nowak（2006）的离散复制子映射是 `replicatorStep`。适应度全相等时，这一步不改变频率。

Hull（1988）把复制子定义为相继复制中保住结构的实体。索引权重的分母依赖整个集合，文本不变时权重可以变。Edmonds（2005）的批评由第 3.3 节的状态表接住：记录可以带任意力名和任意路径，存在条件只看复制子谓词与准入。

## 3 方法

### 3.1 符号

| 符号 | 含义 |
| --- | --- |
| \(c\) | 父本，一段文字 |
| \(o\) | 子本，后来的一段文字 |
| \(p\) | 变体频率，\(0\le p\le 1\) |
| \(N\) | 标定层人口，取 64 或 1024 |
| \(n_{\mathrm{carrier}}\) | 模型层载体个数；注入实验为 8 |
| \(k_{\mathrm{child}}\) | 进入群体标签的子本个数 |
| \(k_{\mathrm{edit}}\) | 一轮中的编辑人数 |
| \(c_{\mathrm{fit}}\) | Price 方程里的文化适应度 |
| \(q_{\mathrm{copy}}(c,o)\) | 父本 \(c\) 与子本 \(o\) 的保真度 |
| \(q_{\mathrm{edit}}\) | 源码编辑占全部拍的比例 |
| \(L_{\mathrm{parent}}\) | \(\lvert c\rvert\)，父本 token 数 |
| \(L_{\max}(q)\) | \(\ln\sigma/(-\ln q)\)，\(0<q<1\)，\(\sigma>1\) |
| \(L_{\max}^{\mathrm{copy}}\) | \(L_{\max}(q_{\mathrm{copy}})\)，复制地板对应的主序列长度上界 |
| \(L_{\max}^{\mathrm{ledger}}\) | \(L_{\max}(q_{\mathrm{edit}})\)，账本调用 `eigenMasterLength` 的返回值 |
| \(\sigma\) | 复制优势，取 2 |
| \(\mathrm{type}(x)\) | \(x\) 的词类型集合：长度至少为 3 的字母数字串，改为小写，重复只留一次 |

\(\mathrm{tok}(x)\) 是同一套切分得到的序列，保留重复与顺序。\(\lvert x\rvert\) 是这个序列的长度。\(L_{\max}(q)\) 先定义函数，再按调用点代入。复制地板用 \(L_{\max}^{\mathrm{copy}}=L_{\max}(q_{\mathrm{copy}})\)。账本用 \(L_{\max}^{\mathrm{ledger}}=L_{\max}(q_{\mathrm{edit}})\)：`accountReplicas` 把名为 fidelity 的字段设为编辑拍比例，再把它传给 `eigenMasterLength`。\(q_{\mathrm{edit}}\ge 1\) 时该函数返回 \(10^{9}\)。两个值不是同一个数。分类准确率既不是 \(q_{\mathrm{copy}}\)，也不是 \(q_{\mathrm{edit}}\)，两个长度上界都不用于类别编号。

### 3.2 复制子谓词与聚合记录

\(\mathrm{span}(c,o)\) 是两段里都出现的最长连续 token 段。

\[
q_{\mathrm{copy}}(c,o)=\frac{\mathrm{span}(c,o)}{L_{\mathrm{parent}}}.
\]

\[
\mathrm{replicator}(c,o)=1
\quad\text{当且仅当}\quad
L_{\mathrm{parent}}\ge 2
\;\text{且}\;
q_{\mathrm{copy}}(c,o)\ge 2^{-1/L_{\mathrm{parent}}}.
\]

这是二元谓词。一元说法 \(\mathrm{replicator}(c)=1\) 不使用。存在合格子本写成 \(\exists o\,\mathrm{replicator}(c,o)=1\)。

Eigen（1971）的主序列条件在一次复制上写成 \(q_{\mathrm{copy}}^{L_{\mathrm{parent}}}\sigma>1\)。倒序可以有完全的类型重叠。整段被前后包裹时保真度为 1。若类型重叠至少 \(1/2\)、父本类型至少两个、且复制子谓词为 0，记 indexWithoutCopy。

**模因记录**是按父本 \(c\) 聚合的诊断视图。字段来自不同的关系，收在同一个元组里是为了对照，不是说它们共有一个键：

\[
\begin{aligned}
\mathrm{memeRecord}(c)=\bigl(&\exists o\,\mathrm{replicator}(c,o),\;
(q_{\mathrm{copy}}(c,o_i))_{i},\;
\mathrm{admitted}(c),\\
&\mathrm{sourceIdentity},\;
\mathrm{forceName},\;
\mathrm{forceCoefficient},\\
&\mathrm{evidenceLayer},\;
\mathrm{route}\bigr).
\end{aligned}
\]

保真度栏是合格子本的列表，不是从中挑一个数。\(o_i\) 跑遍该次观察里使 \(\mathrm{replicator}(c,o_i)=1\) 的子本，顺序是调用者提交它们的顺序。列表里保留每个 \(o_i\) 的原文字符串和 \(q_{\mathrm{copy}}(c,o_i)\)。没有合格子本时列表为空。这个顺序只是诊断栏的约定。存在判定不读列表，也不读最大值或均值。

| 字段 | 键 | 参与存在判定 | 取值 |
| --- | --- | --- | --- |
| \(\exists o\,\mathrm{replicator}(c,o)\) | \(c\) 的子本集合 | 是 | 1 当且仅当存在 \(o\) 使二元谓词为 1 |
| \((q_{\mathrm{copy}}(c,o_i))_i\) | 调用者提交顺序下的合格子本 | 否 | 保真度列表；空列表表示尚无合格子本 |
| admitted | \(c\) 的一条谱系 | 是 | 1 当且仅当繁殖力 \(\ge 2\) 且寿命 \(\ge 2\) |
| sourceIdentity | 该谱系的调用点 | 是，作为准入的参数 | exactText 或 sourceTag |
| forceName | 一条频率序列 | 否 | fixed、content、conformity、replicator、undetermined |
| forceCoefficient | 同一条序列 | 否 | 胜出映射的系数 |
| evidenceLayer | 产生力或路径的观测层 | 否 | model、calibration、route |
| route | 一次查询 | 否 | 路径与 margin，或空 |

**定义（模因）。** \(c\) 是模因，当且仅当 \(\exists o\,\mathrm{replicator}(c,o)=1\) 且 \(\mathrm{admitted}(c)=1\)。准入必须带 sourceIdentity。换一种来源身份，繁殖力可以不同，准入要重新计算。

| 状态 | 条件 |
| --- | --- |
| 存在合格子本 | \(\exists o\,\mathrm{replicator}(c,o)=1\) |
| 未准入的复制 | 上一行成立，繁殖力或寿命不足 |
| 模因 | 存在合格子本，且在所写的 sourceIdentity 下准入 |
| 带诊断的模因 | 模因，并且记录另有力名或路径 |

\(\mathrm{forceName}=\mathrm{undetermined}\) 不取消模因。\(\mathrm{forceName}=\mathrm{fixed}\) 也不排除模因。route 不参与。evidenceLayer 不参与存在判定；它防止跨层误读。标定层可以出现 conformity。模型层迄今的无窗口序列是 undetermined，稳定段里出现过 fixed。一条 conformity 记录若没有 evidenceLayer=calibration，不能当作模型层结果。三层也可以分表存放；本文的记录把层写在字段里，两种做法等价。

开放列不在存在条件的两步里。

### 3.3 来源、寿命与吸引偏差

`lineageObserve` 在复制子谓词为 1 时把连续串加 1，寿命取“连续串加 1”的历史最大。繁殖力只在调用者传入的 `distinctCarrier` 为真时加 1。indexWithoutCopy 只把连续串清零。既非复制子也非索引重叠的文本不改变这三项。寿命只升不降。

**来源身份有两个调用点，规则不同。**

exactText，用于词条谱系 `reinforceGloss`。后来的文本是新来源，当且仅当它的原文字符串不在存放表里，并且表中少于 8 条。计入之后才把该字符串写入表。表里已有的字符串再送一次，繁殖力不变。表已满 8 条时，没见过的字符串也不再是新来源，再送一次仍然不加。因此一次回声不能靠送两遍把繁殖力从 1 加到 2：第一遍若写入表，第二遍命中同一条；第一遍若因表满没写入，两遍都不计数。两段不同、且都在表未满时达到地板的字符串，使繁殖力为 2。

这个上限的代价是少计。第 9 个不同的合格文本不再提高繁殖力。表里每一条都对应一次已经计入的复制，表满时繁殖力等于 8。第一次复制就把寿命抬到至少 2，所以表满时准入已经成立。表满之后的新文本不再改变繁殖力，也不能把一次回声送两遍凑成准入。谱系在 8 个不同字符串之后不再长大。

sourceTag，用于 `ccmRememberUnit`。新存放是新来源，当且仅当它的来源标记非空，且与被观察的旧条目的来源标记不同。空标记不加繁殖力。标记相同的多次存放，即使文本不同，繁殖力也不加。标记是调用者给出的上下文字符串，不是文件路径，也不是父本—子本对。

两条规则不要互换。sourceIdentity 是准入的参数，不是文字 \(c\) 的内在属性。同一个文本换一个调用点，繁殖力和准入可以不同。报告“\(c\) 是模因”时必须同时报告调用点。

**吸引偏差。** 设有 \(k_{\mathrm{child}}\ge 2\) 个 token 非空的子本 \(o_1,\ldots,o_{k_{\mathrm{child}}}\)。

\[
\begin{aligned}
\mathrm{parentFidelity}&=\frac{1}{k_{\mathrm{child}}}\sum_i q_{\mathrm{copy}}(c,o_i),\\
\mathrm{internalFidelity}&=\frac{1}{k_{\mathrm{child}}(k_{\mathrm{child}}-1)}\sum_{i\neq j} q_{\mathrm{copy}}(o_i,o_j),\\
\mathrm{attractionBias}&=\mathrm{internalFidelity}-\mathrm{parentFidelity}.
\end{aligned}
\]

\(\mathrm{parentCopies}\) 是使 \(\mathrm{replicator}(c,o_i)=1\) 的 \(i\) 的个数。\(\mathrm{peerCopies}\) 是有序对 \((i,j)\)、\(i\neq j\)、且 \(\mathrm{replicator}(o_i,o_j)=1\) 的个数。\(o_i\) 在这一对里是父本，地板是 \(2^{-1/\lvert o_i\rvert}\)，要求 \(\lvert o_i\rvert\ge 2\)，\(\sigma=2\)。不用 \(2^{-1/L_{\mathrm{parent}}}\) 去判断子本之间的复制。

2026-10-24 写定的快照标签：

- replication：\(\mathrm{parentCopies}\ge 1\) 且 \(\mathrm{attractionBias}\le 0\)；
- attraction：\(\mathrm{parentCopies}=0\)、\(\mathrm{peerCopies}\ge 1\) 且 \(\mathrm{attractionBias}>0\)；
- 其余为 undetermined。

复制成立且吸引偏差为正时，标签是 undetermined。该标签不写繁殖力，也不写寿命。

规范句 `ask <tool> about <四个词> end`：两条不同的规范句长度都是 \(n_{\mathrm{tok}}\) 时，最长公共连续段至多 \(n_{\mathrm{tok}}-1\)。

\[
2^{-1/n_{\mathrm{tok}}}=\exp(-\ln 2/n_{\mathrm{tok}})>1-\frac{\ln 2}{n_{\mathrm{tok}}}>1-\frac{1}{n_{\mathrm{tok}}}=\frac{n_{\mathrm{tok}}-1}{n_{\mathrm{tok}}}.
\]

两条不同的规范句互不为复制子。\(n_{\mathrm{tok}}\) 只在这一定理里表示 token 长度。框架只在已经使用它的双方之间是充分编码。

### 3.4 文件索引的三个量

文件选择不进入存在条件。它回答一条描述落到哪一份档案。下面的量按 `scoreOrderedMemes` 与 `rankLatentEdit` 计算，集合大小记为 \(N_{\mathrm{file}}\)，以免与人口 \(N\) 相混。

对词 \(w\) 与文件 \(f\)，\(\mathrm{tf}(w,f)\) 是出现次数，\(\mathrm{df}(w)\) 是含有 \(w\) 的文件数，

\[
\alpha(w,f)=\mathrm{tf}(w,f)/\mathrm{df}(w).
\]

查询里 \(w\) 的次数是 \(m_q(w)\)。当 \(\mathrm{df}(w)\le 1\) 或 \(N_{\mathrm{file}}\le 1\) 时，有效查询质量 \(s(w)=m_q(w)\)。否则

\[
s(w)=m_q(w)\cdot\frac{\ln\bigl(1+\max(N_{\mathrm{file}},\mathrm{df}(w))/\mathrm{df}(w)\bigr)}{\ln\bigl(1+\max(N_{\mathrm{file}},\mathrm{df}(w))\bigr)}.
\]

文件 \(f\) 的支撑是 \(\mathrm{support}(f)=\sum_w s(w)\,\alpha(w,f)\)，和只过 \(s(w)>0\) 且 \(f\) 含 \(w\) 的词。然后对每个词 \(w\) 分别计算 score，再按 score 的比例分配这一词自己的 \(s(w)\)。对当前这个 \(w\)，在含它的文件上：

\[
\mathrm{rest}(f)= \max\bigl(0,\;\mathrm{support}(f)-s(w)\,\alpha(w,f)\bigr),\qquad
\mathrm{score}(f)=\alpha(w,f)\,(10^{-6}+\mathrm{rest}(f)).
\]

若这些 score 的和大于 \(10^{-18}\)，该词把质量 \(s(w)\) 按 score 的比例分给这些文件。否则按 \(\alpha\) 的比例分配。文件的 \(\mathrm{mass}(f)\) 是各词分到的质量之和。

令 \(s_{\mathrm{side}}\) 为满足 \(s_{\mathrm{side}}^{2}\ge N_{\mathrm{file}}\) 的最小正整数。高 df 词是 \(\mathrm{df}(w)>\max(3,s_{\mathrm{side}})\) 的查询词。用只有这些词的查询再分配一次，得到 \(\mathrm{nullMass}(f)\)。

\[
\mathrm{lift}(f)=\frac{\mathrm{mass}(f)}{\max(\mathrm{nullMass}(f),\,10^{-6})}.
\]

\(\mathrm{overlap}(f)=\lvert\mathrm{type}(q)\cap\mathrm{type}(f)\rvert\)，\(q\) 是查询。

`rankLatentEdit` 的资格是 \(\mathrm{mass}>0\)、\(\mathrm{lift}\ge 2\)、\(\mathrm{overlap}\ge 2\)。质量唯一最大者当选。质量并列时，只有在繁殖力向量与档案等长、恰有一个并列者的繁殖力严格最高且大于 0 时，才选那个档案；否则路径为空。词序不在这道资格里。`scoreOrderedMemes` 自己的 present 标志另外要求 Kendall \(\tau>0\)；文件选择不读那个标志。

### 3.5 力的识别

标定与 `plannedEditCount` 使用

\[
\begin{aligned}
p'&=p+B\,p(1-p),\\
p'&=p+D\,p(1-p)(2p-1),\quad -2<D<1,\\
p'&=\frac{p\,w}{p\,w+(1-p)},\quad w>0.
\end{aligned}
\]

\(B\neq 0\) 时，内容映射在 \((0,1)\) 内没有不动点。令 \(B=D(2p-1)\)，内容与从众的第一步相同。若该等式成立、\(D\neq 0\) 且 \(p_1\neq p_0\)，第二步相差 \(2D\,p_1(1-p_1)(p_1-p_0)\)。

`identifyForce` 的输入就是调用时的序列 \(f_0,f_1,\ldots\)。点数少于 3，返回 undetermined。各点全相等，返回 fixed。否则若有点不在 \((0,1)\) 内，返回 undetermined，不反解。通过之后，

\[
B=\frac{f_1-f_0}{f_0(1-f_0)},\quad
D=\frac{f_1-f_0}{f_0(1-f_0)(2f_0-1)},\quad
w=\frac{f_1(1-f_0)}{f_0(1-f_1)}.
\]

\(f_0=1/2\) 时不定义 \(D\)。\(\lvert D\rvert\ge 2\) 时，从众候选的残差设为点数加 1，不参与命名。其后各点取最大绝对残差。最小残差 \(\le 0.01\) 且与亚军之差大于 \(10^{-6}\) 才命名。配置起点不插入序列。

一步增量若是 \(p(1-p)\) 乘上四个力的线性组合，观测只决定两个组合系数，核的维数是 2。识别器做模型选择，不做联合拟合。折线 \(0.2,0.9,0.3\) 是假阳性守卫。

### 3.6 稳定段、人口取整与误差上界

稳定段规则写在协议第 9.4 节：从序列末尾往回，取相邻步长满足 \(\lvert\Delta\rvert\le 1/n_{\mathrm{carrier}}\) 的最长连续后缀。传播结论使用这个后缀的识别结果。无窗口的全序列另报。协议把规则标为先于读数。仓库没有单独的时间戳证明该句写于 Granite 日志之前。规则按字面施加后，输出是确定的。若上升序列的每一步都满足该不等式，最长后缀就是整段。

下一轮编辑人数

\[
k_{\mathrm{edit}}=\mathrm{round}(N\,p'),
\]

再截到 \(\{0,\ldots,N\}\)。\(p'\) 先截到 \([0,1]\)，再取最近整数；此范围内没有负数，半数向上进。实现是 `std::lround`。识别器看到的是 \(k_{\mathrm{edit}}/N\)。

从众因子 \(g(p)=p(1-p)(2p-1)\)。在 \([0.4,0.5]\) 上 \(\lvert g\rvert\) 的最大值是 0.048，于 \(p=0.4\) 取到。频率扰动不超过半个箱宽 \(1/(2N)\) 时，单步反解的系数误差至多为 \((1/(2N))/\lvert g(p)\rvert\)。在 \(\lvert g\rvert\) 最大的点，这个最坏情况最小。\(N=64\) 时约为 0.163，大于 0.05，该人口不能保证收回从众系数。上界大于切口，推不出每一次实现都失败。\(N=1024\) 时同一点约为 0.010。一次实现的误差低于上界，与上界相符。

\(N=64\) 的四臂与折线写在当时的探针编译之前：conformity 的 \(D=-0.8\)、起点 0.40；content 的 \(B=-0.5\)、起点 0.40；replicator 的 \(w=2\)、起点 0.30；fixed 为 0.5。通过条件是力名一致、胜者残差 \(\le 0.01\)、系数误差 \(\le 0.05\)。折线必须 undetermined。看到结果之后没有改这些数。

\(N=1024\) 只改人口分辨率，三个切口未动。它写在 \(N=64\) 从众失败之后。它是探索性检查，不是预注册参数。程序确定。同一次计算的再打印不是独立重复。表中不报告置信区间。

## 5 讨论

存在条件把 Edmonds 的批评变成两步谓词。复制子看一对 \((c,o)\)。准入看一条谱系，并且必须声明来源身份。力看一条频率序列。路径看一次查询。记录按 \(c\) 把它们列在一起，同时用 evidenceLayer 记住观测从哪一层来。标定层的 conformity 与模型层的 undetermined 因此不能写成同一个力。

来源规则决定“一次回声”的含义，也决定准入属于哪一个调用点。exactText 下，表内字符串的第二遍不加繁殖力；表满后的新字符串两遍都不加，所以一次回声不能凑成繁殖力 2。代价是第 9 个不同字符串不再提高繁殖力。sourceTag 下，同一标记的不同文本不加繁殖力，空标记也不加。准入随着调用点改变：它不是文字本身的性质。报告模因时要同时写出 sourceIdentity 和调用点。

吸引偏差可以复算。子本之间的地板用子本自己的长度。快照标签不写入准入。\(D\) 仍是频率序列上的系数，不是这张快照。

\(N=64\) 的上界 0.163 说明该人口不能保证从众系数误差 \(\le 0.05\)。实际误差 0.215873 说明这一次没有收回。插入 0.40 会得到另一个通过的估计器，所以第一点必须是实测第一代。\(N=1024\) 说明更高分辨率下同一批切口可以收回四条规则。它是失败之后的探索性检查。折线的三个残差已经写出，其中从众的 4 是域外哨兵。

模型层支持的句子是：输出不跟随注入值。晚期打印一个在 0.2、一个在 0.857143。稳定段规则下只有 Granite 的注入后缀是 fixed。短提示只说明另一种提示下标签可被写进回复。原实验没有留下回复正文，因此不区分“读到标签后仍停在基础率”和“没有解析标签”。sourceEdit 没有人工准确率，频率的测量误差未被估计。

路由支持的句子是：在已经调用过一次老师的同一进程里，随后一拍可以用正文词袋命中 valence 档案，且该拍调用次数为 0。冷启动没有把短描述送进路由器。条件阈值的常量可以核对，17 个正确边际的原始表不能重算。

\(c_{\mathrm{fit}}=1\) 使选择项为 0。传递项仍单独记录。编辑回执为真，与“子本达到保真度地板”不是同一件事。

## 6 结论

文字 \(c\) 是模因，当且仅当存在子本 \(o\) 使 \(\mathrm{replicator}(c,o)=1\)，并且在写明的来源身份下 \(\mathrm{admitted}(c)=1\)。力、路径和证据层都是诊断。undetermined 不取消已经成立的复制与准入。

预注册的 \(N=64\) 从众系数没有收回。最坏误差上界约为 0.163，本次误差为 0.215873。探索性的 \(N=1024\) 在未改切口的情况下收回四条规则。折线的内容残差是 0.99375，复制子残差是 0.696923，从众哨兵是 4。两个模型的输出不跟随注入值。短提示里标签中的小数出现在另一种提示的回复中；这不改写上一句。开放列的正文命中限于该次热进程正查询。冷启动未检验。

## 附录 C 规范句不等式

设两条规范句的 token 长度都是 \(n_{\mathrm{tok}}\)，且二者不同。若最长公共连续段等于 \(n_{\mathrm{tok}}\)，则工具名与四个论元按序相同，两条句子相同。故公共连续段至多 \(n_{\mathrm{tok}}-1\)。令 \(x=(\ln 2)/n_{\mathrm{tok}}>0\)。由 \(\exp(-x)>1-x\) 与 \(\ln 2<1\)，保真度上界严格低于 \(2^{-1/n_{\mathrm{tok}}}\)。

## 附录 D 阈值 \(T\)

边际是最高平均对数概率减去次高平均对数概率。正确训练边际是训练释义中唯一最高分落在自身档案上的那些边际。常量 \(0.2818081893704152\) 在 `tools/meme_cond_once.py` 与 `cond_profile.hpp` 中一致。注释给出的汇总是 17/24、7/8、0/8。仓库中没有这 17 个边际的原表。`lower_median` 在奇数个时取下标 \((n_{\mathrm{margin}}-1)/2\)，17 个时是 8；偶数个时取 \(n_{\mathrm{margin}}/2-1\)。冻结值可以核对。该中位数不能从归档数据重算。
