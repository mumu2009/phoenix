# Phoenix release codenames

| Version | Codename | Status |
|---------|----------|--------|
| 7.x     | Arthur   | shipped (v7.0–v7.9) |
| 8.0     | Lancelot | current |
| 8.1     | Gawain   | planned |
| 8.2     | Galahad  | planned |
| 8.3     | Percival | planned |
| 8.4     | Ganis    | planned |
| 8.5     | — (none) | planned; no codename, see rule below |
| 8.6     | Gareth   | planned |
| 8.7     | Bedivere | planned |
| 8.8     | Kay      | planned |
| 8.9     | Gaheris  | planned |
| 8.10    | Lamorak  | planned |

The naming decree comes from `v7.0.md`: v7.0 = Arthur; from 8.0 onward the
codenames are Lancelot, Gawain, Galahad, Percival, Ganis, Tristan, Gareth,
Bedivere, Kay, Gaheris, Lamorak.

**Rule (corrected):** only major versions (x.0.0) carry a codename. Minor
versions (8.x.0) and debug/patch versions (8.5.x) have NO codename. 8.5.0
therefore ships without a codename; the earlier "Tristan" plan for 8.5 is
withdrawn.
