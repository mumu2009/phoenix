# v5.2 发布说明

## 1. 发布定位

v5.2 是一个“工程能力已成型、研究目标未全部闭环”的版本。

适合用于：

1. 本地系统 API 与直连模型的质量/性能对比。
2. GGUF 模型解析、外部后端接入与运行时监控。
3. 多后端、自治栈、人格调度和 benchmark 管线验证。

不应被表述为：

1. 已完成完整 GGUF 到脑式动力学模型的自动转换。
2. 已完成 LoRA 转换与回退体系。
3. 已完成滑动窗口按需权重装载和全部消融实验。

## 2. 本版已知可用能力

1. API 回归、智能评估和性能 benchmark 三套测试链路可运行。
2. system API 与直连 Ollama 的全量外部集对比可落盘为 Markdown、JSON、PDF。
3. GGUF 解析能力与本地后端状态监控已落地。
4. 数学桥接已可调用 `outsides/_calculator`。
5. Phoenix benchmark 已支持自动拉起、system warmup 探测与中途断连恢复。

## 3. 已知限制

1. `doc/external_dataset_index.json` 当前只是索引元数据，不是本地可直接评测的样本集。
2. 词元级语义拆分、梯度拟合、滑动窗口按需装载等仍属于研究目标，未应宣称为已完成能力。
3. 外部工具调用目前已有超时与进程级隔离，但不是完整沙箱。
4. LoRA 转换限制仍未形成正式的检测与回退实现。
5. “几乎 100% 覆盖率”只能按 [coverage.md](coverage.md) 中的分层口径理解，不能等同于单一语句覆盖率。

## 4. 最小复现实验

最小一键验证脚本：

1. [test-tools/repro_v52_full.bat](test-tools/repro_v52_full.bat)

该脚本会依次执行：

1. `compile.bat`
2. API 回归
3. intelligence 评估
4. 全量外部集性能测试
5. PDF 汇总导出

## 5. 后续路线图

1. 完成 GGUF 结构化导出模块。
2. 完成 LoRA 不可转换条件与回退策略。
3. 完成滑动窗口按需装载与长上下文基准。
4. 完成词级/词元级/混合粒度消融实验。
5. 完成外部工具安全沙箱与审计日志。
