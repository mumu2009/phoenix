# v5.2 术语表

## 1. 术语统一原则

v5.2 中与语义切分相关的术语必须固定使用以下定义，避免同一个词在不同文件里表示不同层级。

## 2. 正式定义

### 2.1 词语

词语是自然语言中的表层语义单位，通常对应人类书写或阅读时直觉上可识别的一个词或短语。它面向语言使用习惯，不保证与模型内部切分单元一致。

### 2.2 词元

词元是模型计算过程中使用的离散编码单元，是 tokenizer 实际输出的计算单位。一个词语可以对应一个词元，也可以对应多个词元；多个词语也可能共享部分词元片段。

### 2.3 词素

词素是语义上的最小构成单位，强调意义组合，而不是编码方式。词素比词语更细，未必等于 tokenizer 的词元，但可以作为 v5.2 中“语义重分辨率”阶段的目标单元。

### 2.4 语义最小单位

语义最小单位是 v5.2 文档中的总称，表示在当前任务和映射规则下不再继续拆分、且仍保留独立语义功能的最小单元。它可以具体实现为：

1. 一个词元
2. 一个词素
3. 一个由上下文约束的语义片段

因此，“语义最小单位”是抽象层概念，“词元”和“词素”是可能的实现形式。

## 3. 层级关系

在 v5.2 中采用以下层级：

1. 词语：面向自然语言表层。
2. 词元：面向 tokenizer 和模型编码。
3. 词素：面向语义组合结构。
4. 语义最小单位：面向算法映射后的统一抽象对象。

关系可以概括为：

1. 词语不等于词元。
2. 词元不必等于词素。
3. 语义最小单位是算法内部的最终对齐单位。

## 4. 在 v5.2 文档中的固定用法

为避免混淆，后续文档一律按以下规则书写：

1. 讨论 tokenizer 输出时，只使用“词元”。
2. 讨论自然语言意义拆分时，优先使用“词素”。
3. 讨论算法最终处理对象时，使用“语义最小单位”。
4. 只有在说明人类语言现象时，才使用“词语”。

## 5. 相关术语

### 5.1 语义重分辨率

指把原有 token 粒度表示重新映射到更细或更稳定的语义粒度，以减少单一 token 承载过多语义造成的混叠。

### 5.2 权重共享池

指多个语义最小单位共享同一组或部分参数，以表达近义词、变体词或同功能片段之间的统计共性。

### 5.3 动力学参数

指从 Transformer 静态权重映射得到的阈值、电导、时间常数、重置电流、平衡电位等参数。

### 5.4 人格库

指一组经微调或拟合后的人格子模型集合，用于多角色仿真、社会模拟和按需调度。
