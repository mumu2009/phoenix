# 复杂度下限与当前实现（信息论视角）

目标：使每个热点操作逼近其**信息论复杂度下限**。该目标**注定无法完全达成**——常数因子、对数因子、近似-精确鸿沟、块粒度损失、在线-离线矛盾。本文对每个操作给出：下限（含证明或引用）、我们实现的上限、以及“不可达部分”的精确刻画。

---

## 1. 通用工具

**信息论下限**：要区分 n 个候选，决策树（比较模型）深度 ≥ log₂ n（每次比较最多二分候选集，2^d ≥ n ⇒ d ≥ log₂ n）。

**Johnson–Lindenstrauss（JL）引理**：对任意 n 点集 X ⊂ R^d 与 ε ∈ (0,1)，存在 f: R^d → R^k，k = O(ε⁻² log n)，使所有 x,y ∈ X：

$$ (1-\varepsilon)\|x-y\|^2 \le \|f(x)-f(y)\|^2 \le (1+\varepsilon)\|x-y\|^2 $$

**紧性（Alon 2003）**：存在需要 k = Ω(ε⁻² log n / log(1/ε)) 维的点集——JL 的维度在（几乎）常数因子内不可改进。稀疏变体（Kane & Nelson 2014）用每行 s = O(ε⁻¹ log n) 个非零元达到同阶保证。

## 2. 逐操作分析

### 2.1 向量投影 `projectToDimension` / `projectToDimensionSparse`

- **下限**：按 JL 紧性，把 n 个概念嵌入统一空间并保持成对距离，目标维 k 需 Ω(ε⁻² log n)。对 n=4096、ε=0.1：k ≈ 8·ln(4096)/0.01 ≈ 6650——高于我们常用的 128/4096 维，说明当前维度选择是“工程折衷”而非达到下限（见差距）。
- **实现**：稠密 O(D_in·D_out)；稀疏（D_in·D_out > 4096 自动启用）O(s·D_in)，s = max(3, D_out/3)，±1/√s 每列 s 个非零（确定性，seed 固定）。
- **不可达部分**：(a) JL 的最优常数非常数可构造；(b) 我们的 s 是固定启发式，未按 n、ε 调优；(c) 维度本身受下游模型（llama 8b 隐空间 4096）约束，不能自由取到 JL 最优。

### 2.2 最近邻 `PersistentConceptMatrix`（LSH）

- **精确下限**：高维精确最近邻受“维数灾难”约束——在 SETH 假设下，要么查询 n^{1−o(1)} 时间，要么指数空间（Alman & Williams；Rubinstein 2018）。**结论：高维精确 NN 不可达，近似（LSH）是必然选择而非纯优化。**
- **实现（随机超平面 LSH, Charikar 2002）**：L=8 张表、每表 b=16 位高斯超平面；查询 O(L·b·D + |候选|·D)。碰撞概率 P = 1 − θ/π（θ 为夹角）。对 θ ≤ 18.2°（sim ≥ 0.95，即“近重复原型”场景）：单表碰撞 P^b = 0.949^16 ≈ 0.43，8 表的召回 ≥ 1 − (1−0.43)^8 ≈ **0.989**。
- **安全阀**：候选为空、或候选最优相似度 < 0.95 时回退精确扫描（最坏情形绝不劣于暴力）；N ≤ 256 或 D < 32 直接暴力（LSH 开销不划算）。
- **不可达部分**：召回 < 1（近似误差）；低相似度区间（<0.95）无加速。

### 2.3 稀疏矩阵乘 `sparse_block_matmul`

- **精确下限**：Ω(nnz(A))。证明：若算法不读取非零元 a_ij，则把 a_ij 扰动 ε 后输出必须不变（算法未读它），但精确输出 C 的第 (i,·) 行会改变 ε·B_{j,·}——矛盾。即“×0 不计算”的理想极限就是 nnz(A)，不可能更低。
- **实现**：块粒度跳过（32 行/块），τ=0 精确（逐位一致），复杂度 O((1−s)·M·N·K)，s = 块级稀疏率。
- **不可达部分**：块内稀疏零无法跳过（若 s_block 为块内零密度，理想是乘 (1−s_entry)，我们只能乘 (1−s_block)，差距 = 块内零的残余计算）；逐元素跳过会破坏 SIMD 反而更慢（见 llamacpp_optimization.md §3.1）。

### 2.4 余弦相似度 / 2.5 注意力融合

- 余弦：下限 Ω(D)（必须读两个向量），实现 O(D)——**已达**。
- `fuseAttention`：下限 Ω(K·D)（读输入）+ Ω(K)（softmax 归一化），实现 O(K·D)（投影单次物化后 O(K·D_out)）——**已达常数级**。

### 2.6 TD(0) 收敛（自我进化的价值学习）

- **定理（Tsitsiklis & Van Roy 1997）**：步长 Σα_t = ∞ 且 Σα_t² < ∞ 时，线性函数近似的 TD(0) 以概率 1 收敛到 TD 不动点 w* = A⁻¹b。
- **实现**：常数 α + 权重钳制 [-V_max, V_max]。放弃极限收敛，换取**有界性 + 非平稳跟踪**（生存智能体必须跟踪漂移的回报分布——收敛到不动点的智能体无法适应变化）。
- **不可达部分**：极限收敛与持续适应不可兼得（这是目标“注定无法达成”的在线-离线矛盾）。实测（protocol §2.1）：平稳环境学习曲线单调下降、10/10 种子通过——钳制版达到“实用收敛”。

### 2.7 概念寻址/存储

- 下限：区分 N 个概念需 ≥ log₂ N 位/概念。
- 实现：64 位 FNV-1a 指纹（N ≤ 4096 时 12 位即够）——**已达**。

## 3. 总结表

| 操作 | 信息论下限 | 当前实现 | 差距性质 |
|---|---|---|---|
| 投影 | k = Ω(ε⁻² log n)（JL 紧） | 稠密 O(D²) / 稀疏 O(s·D) | 常数 + 维度受下游约束 |
| 精确最近邻 | 高维不可行（SETH） | LSH 近似 O(L·b·D) | 召回 < 1（必然） |
| 稀疏矩阵乘 | Ω(nnz(A)) | O((1−s)·M·N·K) 块级 | 块内零残余 |
| 余弦 | Ω(D) | O(D) | **已达** |
| 注意力融合 | Ω(K·D) | O(K·D) | **已达常数级** |
| TD(0) | 收敛需衰减步长 | 常数步长 + 钳制 | 在线-离线矛盾（不可兼得） |
| 概念寻址 | Ω(log₂ N) 位 | 64 位 | **已达** |

---

## 4. “注定无法达成”的精确含义

1. **常数因子**：JL、LSH 的最优常数非构造性已知。
2. **对数因子**：log(1/ε)、log n 等出现在所有信息论下界中。
3. **近似-精确鸿沟**：高维精确 NN 在 SETH 下不存在次指数时间算法——我们只能逼近。
4. **块粒度损失**：稀疏乘法无法跳过块内零。
5. **在线-离线矛盾**：收敛（离线最优）与适应（在线必需）不可兼得。

因此：正确目标不是“达到下限”，而是**在每个操作上把差距缩小到一个明确的、有引用的常数/对数因子内**，并让差距可测（见 testing_methodology.md）。
