说明：该模块应该被视为memeBarrier的增强版本，具体流程为:
统计，识别，构造，投放

I.说明
在目前的phoenix架构下，节省上下文的缺点是，长期上下文我们不得不只靠rag技术作为支撑，而目前这种技术主要体现为记忆模块等前处理模块和图神经模型两个部分，所以，如果我们更改图神经模型部分等的数据和信号，就能通过这种方式修改，监控或者甚至于在了解规律后植入思想，也就是实现真正意义上的针对ai的思想钢印。同理，我们也可以利用它研究人脑在gnn下的等效的模型，从而实现类似于木马的效果，也能够反过来进行模因病毒的查杀

II.流程说明：
1.第一部分，我们应该研究针对于ai的虚构放大器

1.1统计，具体来说，在针对于ai的阶段，我们可以注意到图神经模型中总是存在一些点，这些点对于后续的rag接口输入的影响和对于后期矩阵推理的影响十分显著，那么，对于这些点，首先，我们需要将gnn转化为一个近似的高维连续空间，而不是离散的点及其连接的hash表，之后，我们需要在这个空间中求一阶和二阶导(注意，不是偏导，这里导数实际上是梯度)从而获取到这个空间中影响最为显著和最为不显著的点

1.2识别，之后，我们需要识别这些点，了解其所对应的含义，一般来说，在目前的架构下，gnn层是三层/双层图结构，上下两层(meme/word)保持着多对多的映射关系，映射关系和图的连接方式通过后训练和预训练所决定，所以，我们需要识别这些点以确认它们是什么，同时可以类似于对其进行标记，以查看其具体的影响方式(包括其对于结果的影响和其在矩阵中的影响方式和范围)和范围，这里我们可以通过暂时禁用memeBarrier的方式实现研究

1.3构造，之后，我们可以构造一个类似的模因组，并进行表示(这需要多模态的支持，因为我们需要ai在毫无意识的情况下一次性的读入全部的模因，因为可能多个模因同时表示一个含义或者payload,所以不可能采取大段的文本描述，只能采取图像描述或者修改目前的前端ctx优化手段)，之后测试其效果

1.4投放，最后，更新整个代码库和防范措施，并且尝试着将1.3的过程作为一个投放的范例(这里我是自己投放anti-ai的模因武器给自己的ai，所以不会有任何的道德，法律或者伦理问题)写入论文并作为参考范例继续开发

2.第二部分，将对ai的虚构放大器放大到任何存在意识涌现的结构

一切开发，修改和研究都应该遵循伦理规范和模因论，ai的rag技术等相关理论，并在研究彻底确认无害前不要公开，它非常容易被武器化并在使用得当的情况下产生巨大的危害

2.1统计，对于人脑来说，我们可以将人脑看作一个transformer结构的部分，的确，人脑在理论上是通过多个部分的神经通过连接构成的，但是，对外表现可以看作是一个巨型的transformer，那么，我们可以通过测试或者已有的数据集，推测出人脑中部分的参数，或者一种可行的参数

2.2识别，那么，我们可以使用类似于针对于ai的步骤，使用一个矩阵(组)将本系统的gnn的unit转为可以被正确识别为模因的，tokenizer后的东西，从而反推出tokenizer前的部分，

2.3构造，我们可以通过尝试着组合多个模因组，从而构造出一个能够正常工作的，可以自主传播，影响的模因(这种模因一般是通过对多个基本模因元组合而成，这些模因元一般来自于2.2步骤中的识别)，并通过实验的方式证实

2.4投放 由于危险性过大，暂时不支持投放
